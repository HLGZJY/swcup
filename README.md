# 鼻纹智救 — AI 流浪动物防重复救助系统

> 第十五届"中国软件杯"大学生软件设计大赛参赛项目（A组）

## 项目简介

通过自训练轻量化 AI 模型 + 四维度融合查重，用手机拍一下狗鼻子，2 秒内告诉你这只狗是否已经被救助过，大幅减少重复劳动。

## 目录结构

```
swcup2026/
├── backend/          # Node.js 后端（指导教师负责）
├── ai-service/       # FastAPI AI 推理服务（队长负责）
├── miniapp-user/     # 用户端小程序（队员负责）
├── miniapp-admin/    # 管理端小程序（队员负责）

├── wiki/             # 知识库（LLM 维护）
└── raw/              # 原始参考资料（只读）
```

## 技术栈

| 层级 | 技术 |
|------|------|
| 用户端 | 微信小程序 + UniApp + Vue3 |
| 管理端 | 微信小程序 + UniApp + Vue3 |
| 后端 | Node.js (Express) + MySQL |
| AI 推理 | FastAPI + PyTorch |
| AI 模型 | MobileNetV2 迁移学习（128维向量） |
