## 方案核心变更（对比 v1）

| v1 做法 | v2 改为 |
|---------|---------|
| VGG16 迁移学习 | MobileNetV2（移动端推理更快） |
| 纯鼻纹特征比对 | 四维度融合查重（向量40%+位置20%+图片20%+文本20%） |
| 独立文档 8 个 | 合并为 3 份核心文档 + 代码内 README |
| 管理端独立 Web 后台 | 降级为内部测试账号演示 |
| INT8 量化 / 边缘部署 | 删除（初赛无需此工程优化） |
| 兼容性测试报告、性能测试报告 | 删除（形式大于内容） |
| 纸质报名表提前操心 | W8 再准备，决赛才用 |
