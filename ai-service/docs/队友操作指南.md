# 鼻纹智救 - AI 服务队友操作指南

> 本文档供队友在**另一台电脑**上运行 AI 模型训练和推理服务。

---

## 一、环境准备

### 1.1 安装 Python

推荐 **Python 3.10 或 3.11**（不支持 3.12）

下载地址：https://www.python.org/downloads/

安装时**务必勾选** `Add Python to PATH`

### 1.2 克隆代码

```bash
git clone <仓库地址>
cd swcup2026/ai-service
```

### 1.3 安装依赖

```bash
cd ai-service
pip install -r requirements.txt
```

如果 `pip` 找不到，试试：
```bash
python -m pip install -r requirements.txt
```

> 注意：PyTorch 安装包较大（约 200MB），确保网络稳定。
> 如遇超时重试即可。

## 三、训练模型（可选，W3 才用到）

### 3.1 数据集准备

数据集格式：每个类别一个文件夹，文件夹名为类别名（狗的名字/ID）：

```
dataset/
├── dog_001/
│   ├── photo1.jpg
│   ├── photo2.jpg
│   └── ...
├── dog_002/
│   ├── photo1.jpg
│   └── ...
└── dog_003/
    └── ...
```

每只狗就是一个类别，同一只狗的多张照片放同一个文件夹。

**数据集来源：**
- Oxford Pets 数据集（https://www.robots.ox.ac.uk/~vgg/data/pets/）
- 自己采集的狗鼻纹照片
- 狗鼻纹开源数据集（images.cv 等）

### 3.2 开始训练（阶段一）

```bash
python -m src.scripts.train_stage1 \
  --data ./dataset \
  --epochs 10 \
  --batch 32 \
  --lr 0.001 \
  --output weights/stage1.pth
```

**参数说明：**
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--data` | 必填 | 数据集路径 |
| `--epochs` | 10 | 训练轮数 |
| `--batch` | 32 | 批大小（显存不够就调小） |
| `--lr` | 0.001 | 学习率 |
| `--output` | weights/stage1.pth | 输出权重路径 |

**无 GPU 时用 CPU（很慢，不推荐）：**
```bash
python -m src.scripts.train_stage1 --data ./dataset --device cpu
```

### 3.3 训练完成

训练完后：
- 权重保存在 `weights/stage1.pth`
- 评测指标：准确率
- 下一步（W4）：解冻 backbone，加 ArcFace Loss，继续微调

## 四、常见问题

### Q: `ModuleNotFoundError: No module named 'torch'`

```bash
pip install torch torchvision
```

### Q: `pip 不是内部命令`

在 Windows 开始菜单找 **"Python 3.x Manuals"** 或 **"Manage App Execution Aliases"**，确保 Python 和 pip 路径已添加。

或直接用：
```bash
python -m pip install -r requirements.txt
```

### Q: 图片路径找不到

Windows 路径用反斜杠或正斜杠都可以：
```bash
# 这两种都行
python single_image_test.py C:\Users\xxx\dog.jpg
python single_image_test.py C:/Users/xxx/dog.jpg
```

### Q: 训练时显存不够（OOM）

减小 batch size：
```bash
python -m src.scripts.train_stage1 --data ./dataset --batch 8
```

### Q: uvicorn 启动后 curl 访问不到

这是 WSL2/Windows 网络环境问题，不影响训练。使用 `test_api.py` 测试 API 即可，或用 `python single_image_test.py` 直接做推理。

## 六、技术架构（了解即可）

- **模型**：MobileNetV2（ImageNet 预训练） + 128维输出层
- **训练策略**：阶段一冻结 backbone 只训练输出层，阶段二微调
- **损失函数**：阶段一用 CrossEntropy，阶段二用 ArcFace
- **向量维度**：128维，L2 归一化输出
- **相似度度量**：余弦相似度
