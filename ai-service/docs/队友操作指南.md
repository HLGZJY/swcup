## 一、环境准备

### 1.1 安装 Python

推荐 **Python 3.10 或 3.11**（不支持 3.12）

下载地址：https://www.python.org/downloads/

安装时**务必勾选** `Add Python to PATH`

### 1.2 拉取最新代码

```powershell
cd F:\ai-server\ai-service
git pull
```

### 1.3 安装依赖

```powershell
cd F:\swcup2026\ai-service
pip install -r requirements.txt
```

如果 `pip` 找不到，试试：

```powershell
python -m pip install -r requirements.txt
```

### 1.4 验证 GPU 可用

```powershell
python -c "import torch; print(f'GPU可用: {torch.cuda.is_available()}'); print(f'GPU型号: {torch.cuda.get_device_name(0) if torch.cuda.is_available() else \"无\"}')"
```

应该输出 `GPU可用: True`。

## 三、训练模型（三阶段流程）

### 3.1 数据集准备

**Oxford Pets（阶段一用，最简单）：**

- 地址：https://www.robots.ox.ac.uk/~vgg/data/pets/
- 下载：Images (757MB) + Lists (0.5MB)
- 解压到 `F:\swcup2026\ai-service\scripts\oxford_pets\`

**images.cv 狗鼻纹（阶段二用）：**

- 地址：https://images.cv/dataset/dog_nose-image-classification-dataset
- 参数：Image size=original, Color=color, Augmentation=全选
- 解压到 `F:\datasets\dog_nose\data\train`

### 3.2 转换 Oxford Pets 格式

```powershell
python scripts/convert_oxford_pets.py
```

### 3.3 阶段一：Oxford Pets（30轮）

```powershell
python src/scripts/train_stage1.py --data "D:\ai-server\ai-service\oxford_pets_split\train" --epochs 30 --batch 32 --lr 0.01 --embed-dim 512 --output "weights\stage1_oxford.pth"
```

### 3.4 阶段二：images.cv 狗鼻纹（30轮）

```powershell
python src/scripts/train_stage1.py --data "D:\ai-server\ai-service\dog_nose\data\train" --epochs 30 --batch 32 --lr 0.001 --embed-dim 512 --output "weights\stage2_dognose.pth" --resume "weights\stage1_oxford.pth"
```

### 3.5 阶段三：Stanford Dogs（可选，30轮）

```powershell
python src/scripts/train_stage1.py --data "D:\ai-server\ai-service\Stanford_Dogs" --epochs 30 --batch 32 --lr 0.001 --embed-dim 512 --output "weights\stage3_stanford.pth" --resume "weights\stage2_dognose.pth"
```

### 3.6 断点续训

```powershell
# 继续训练同一个模型
python src/scripts/train_stage1.py --data "你的数据集路径" --epochs 30 --batch 32 --lr 0.001 --embed-dim 512 --output "weights\stage2_dognose.pth" --resume "weights\stage2_dognose.pth"
```

## 四、常见问题

### Q: GPU 训练报错 "out of memory"

减小 batch size：

```powershell
python src/scripts/train_stage1.py --data "你的路径" --batch 16
```

### Q: 准确率一直只有 20-30% 不涨

检查：

1. 数据集路径是否正确
2. 图片是否能打开
3. 拉取最新代码：`git pull`

### Q: 换数据集后准确率反而低了

正常，新数据集的分类头需要重新学习。继续训练会回升。

### Q: 训练中途停止

随时 Ctrl+C 不会丢失数据，权重文件里保存的是历史最佳模型。

## 六、技术架构（了解即可）

- **模型**：MobileNetV2（ImageNet 预训练） + 512维输出层
- **训练策略**：阶段一冻结 backbone，阶段二微调 backbone
- **断点续训**：通过 `--resume` 参数加载已有权重继续训练
- **向量维度**：512维，L2 归一化输出
- **相似度度量**：余弦相似度
