## 二、训练前先准备数据集

### 2.1 数据集是什么格式？

训练脚本要求图片**按文件夹分类存放**，就像这样：

```
dataset/
├── dog_001/          ← 每一只狗是一个文件夹
│   ├── photo1.jpg    ← 这只狗的多张照片
│   ├── photo2.jpg
│   └── photo3.jpg
├── dog_002/
│   ├── a.jpg
│   └── b.jpg
├── dog_003/
│   └── ...
...
```

**文件夹名就是标签**（狗的编号），同一只狗的多张照片放同一个文件夹。

### 2.2 模型训练的是"整体特征"，不只是鼻纹

这是给完全不懂AI的朋友看的解释：

**我们的模型本质是：**

```
输入：一张狗的图片（不管拍的是鼻子、狗脸、还是全身）
        ↓
MobileNetV2 特征提取器（像一个"阅狗无数的眼睛"）
        ↓
128维向量（像是给这只狗生成的"身份证号"）
```

**训练的时候模型在学什么？**
- 它不是只学"鼻纹"这一小块
- 它学的是整张图片里**所有能区分不同狗的特征**
- 包括：鼻纹纹理 + 鼻子形状 + 毛发颜色分布 + 眼睛形状 + 整体轮廓 ...

**类比**：就像你记住一只狗，不需要盯着它的鼻子看。看一眼整体，下次远远地就能认出来。

**用 Oxford Pets（狗脸）和用狗鼻纹数据集训练有什么区别？**

| 数据集 | 学到的特征重点 | 适合场景 |
|--------|-------------|---------|
| Oxford Pets（狗脸） | 区分不同品种（37类） | 能分品种，不能很好地区分同品种的不同个体 |
| images.cv 狗鼻纹 | 区分不同个体 | 更贴近实际使用场景（防重复救助需要区分个体） |

**实际项目中的策略：**
1. 先用 Oxford Pets 预训练（学到狗的基本特征，快速出结果）
2. 再用狗鼻纹数据 fine-tune（学到鼻纹细节，更精准）

### 2.3 去哪里下载数据集？

**推荐数据集①：Oxford Pets（最简单，推荐先下这个）**

- 地址：https://www.robots.ox.ac.uk/~vgg/data/pets/
- 下载：进网站找 "Download" → "Images" + "Lists, with train/test splits"
- 数据量：37类宠物（25种狗 + 12种猫），每类约200张，共 7400 张
- 说明：图片已经按品种分好文件夹，拿来直接能用

**需要下载的文件：**

| 文件 | 大小 | 必须？ |
|------|------|--------|
| Images | 757MB | ✅ 必须 |
| Lists, with train/test splits | 0.5MB | ✅ 建议下（官方划分好的训练/测试集） |
| Annotations | 21MB | ❌ 不用下（边界框标注，训练用不上） |

**推荐数据集②：images.cv 狗鼻纹数据集（专门针对鼻纹）**

- 地址：https://images.cv/dataset/dog_nose-image-classification-dataset
- 搜索关键词："dog nose" 或 "canine nose"

**images.cv 参数怎么选：**

| 参数 | 选什么 | 原因 |
|------|--------|------|
| Image size | **original（原本大小）** | 保留最完整的鼻纹细节，训练时会自动 resize 到 224 |
| Color mode | **color** | 必须 RGB，我们模型用 3 通道 |
| Train/Val/Test | **70/15/15（默认）** | ✅ 保持不变 |
| Augmentation | **Check all（全选）** | 增加数据多样性，对小数据集特别有用 |

> 💡 **提示**：augmentation 里 ~30% 的训练图会被随机增强，每张只增强一次，所以选全不会叠加副作用。

**下载回来的压缩包结构（images.cv）：**

```
dog_nose/
├── meta.json              # 标签信息（不用管）
└── data/
    ├── train/
    │   └── <狗的类别>/*.jpg   ← ~70%图片
    ├── val/
    │   └── <狗的类别>/*.jpg   ← ~15%图片
    └── test/
        └── <狗的类别>/*.jpg   ← ~15%图片
```

**这就是训练脚本要求的格式**，直接就能用。

### 2.4 数据不够怎么办？自采集

手机拍照也行！规则：
- 每只狗至少 3-5 张不同角度的照片
- 尽量光照均匀，不要过曝或过暗
- 把照片放到以"狗的编号"命名的文件夹里

示例：
```
my_dataset/
├── self_001/
│   ├── dog1_front.jpg
│   ├── dog1_left.jpg
│   └── dog1_right.jpg
├── self_002/
│   ├── dog2_1.jpg
│   └── dog2_2.jpg
```

### 3.3 开始阶段一训练（冻结backbone）

**什么是"冻结backbone"？**  
人话版：MobileNetV2 是个成熟的"眼睛"，已经看过几百万张图片，它识别图案的能力已经很好了。我们不改变它的能力，只训练它后面新加的"读脑"层。这个过程很快，适合打底。

**参数解释（RTX 4060 队友用这个配置）：**

| 参数 | 意思 | RTX 4060 推荐值 | CPU 推荐值 | 说明 |
|------|------|----------------|-----------|------|
| `--data` | 数据集路径 | 你的路径 | 你的路径 | 放按文件夹分类好的图片 |
| `--epochs` | 训练多少轮 | **30** | 30 | 越多越慢，但通常更准 |
| `--batch` | 一次喂多少张图 | **64** | 32 | RTX 4060 32GB 显存大，可以设大些 |
| `--lr` | 学习率 | **0.01** | 0.01 | 控制更新步子大小 |
| `--embed-dim` | 输出向量维度 | **512** | 512 | 128维太弱，推荐512 |
| `--output` | 模型保存路径 | weights/stage1_512d.pth | weights/stage1_512d.pth | 训练完的权重文件 |

> **为什么 RTX 4060 用 --batch 64？**
> 32GB 显存非常充裕，batch 越大训练越稳定、梯度估计越准确。
> 跑完 30 轮 Epoch 也就 5-10 分钟，完全不用担心。

### 3.4 训练过程发生了什么？（小白概念）

```
第1轮：模型随机猜测 → 准确率 ~30%（37类中猜对一个的概率）
第5轮：开始学到东西 → 准确率 ~55%
第10轮：基本学会 → 准确率 ~70%
第15轮：可能过拟合 → 准确率 ~75% 但在测试集上开始下降
```

每轮训练完会在验证集上测试一次，准确率最高的那次模型会被保存。

## 五、W4 阶段二预告（提前了解）

阶段一只是"能用"，阶段二要"好用"：

| 阶段 | 方法 | 目标准确率 | 改动 |
|------|------|-----------|------|
| 阶段一 | 冻结 backbone，只训练 fc 层 | ≥70% | 改动小，快速出结果 |
| 阶段二 | 解冻最后2个卷积块 + ArcFace Loss | ≥85% | 改动大，效果好 |

**阶段二用到的 ArcFace Loss 是什么？**  
人话版：让同一条狗的照片在向量空间里靠得更近，让不同狗的照片离得更远。比普通分类训练更适合"比对"场景。

**为什么阶段二更好？**
- 阶段一训练的是"分类"：让模型学会把图片分到正确的类别
- 阶段二训练的是"比对"：让模型学会判断两张图片是不是同一只狗

对于"防重复救助"这个场景，阶段二的"比对"思路更贴合实际需求。

## 六、常见问题

### Q：GPU 训练报错 "out of memory"
A：减小 batch 大小，把 `--batch 32` 改成 `--batch 8` 或 `--batch 16`

### Q：下载数据集太慢
A：用 IDM 或迅雷下载，或者用网盘找别人分享的 Oxford Pets

### Q：训练到一半停了
A：当前脚本是覆盖模式，重新运行会重新开始。重要结果记得备份 `weights/stage1.pth`

### Q：准确率只有 50% 就上不去了
A：检查数据是否正确分类，图片是否清晰，可能需要更多数据

### Q：Windows 上跑训练很慢
A：正常，CPU 训练比 GPU 慢 10-20 倍。阶段一10轮可能需要1-2小时，耐心等

### Q：为什么第一轮训练准确率只有 0.77%（和随机猜测差不多）？
A：**完全正常，不用担心。** 原因如下：

| 原因 | 解释 |
|------|------|
| 分类头是从零开始 | backbone（MobileNetV2）是冻结的，只有新加的 `Linear(512→120)` 是随机初始化的 |
| 128→512 维压缩丢失信息 | ImageNet 1000类的信息压缩到 512 维，很多细粒度特征被丢弃 |
| Stanford Dogs 是细粒度分类 | 120个品种的狗，差别很小，随机猜测概率 ≈ 0.83%，0.77% ≈ 从零起步 |

**训练几轮后准确率变化趋势：**
```
第 1 轮：  ~1%（随机猜测）
第 5 轮：  ~40%（开始学到东西）
第 15 轮： ~60%（基本学会）
第 30 轮： ~70%（收敛）
```

> 只要第 5 轮能到 30-40%，就说明模型在正常学习。如果一直是 1%，才要检查代码或数据。

### Q：Oxford Pets 和狗鼻纹数据集哪个好？
A：先用 Oxford Pets 跑通流程，再用狗鼻纹数据集 fine-tune。两者结合效果最好。

### Q：images.cv 的 augmentation 要不要全选？
A：建议全选。页面上说 ~30% 的训练图会被增强，每张只增强一次，选全不会叠加副作用。
