## 一、训练流程总览

训练分三个阶段，逐步切换数据集：

```
阶段一（Oxford Pets）  →  阶段二（images.cv 狗鼻纹）  →  阶段三（Stanford Dogs）
37类，约7400张，容易出效果     更贴近实际鼻纹场景            120类细粒度分类，最终模型
目标准确率：≥80%             目标准确率：≥70%              目标准确率：≥60%
预计时间：10-15分钟           预计时间：10-15分钟           预计时间：15-20分钟
```

**每个阶段产出的权重文件是下一个阶段的起点**，不需要从零开始。

## 四、阶段一：Oxford Pets 预训练

### 目标

用 Oxford Pets（37类）验证训练流程正常，积累通用的狗/宠物特征。

### 命令（单行）

```powershell
python src/scripts/train_stage1.py --data "D:\ai-server\ai-service\oxford_pets_split\train" --epochs 30 --batch 32 --lr 0.01 --embed-dim 512 --output "weights\stage1_oxford.pth"
```

### 预期结果

| 轮数     | 准确率  | 说明                          |
| -------- | ------- | ----------------------------- |
| 第 1 轮  | ~20-30% | 正常，预训练特征 + 随机分类头 |
| 第 5 轮  | ~55%    | 开始学到东西                  |
| 第 10 轮 | ~70%    | 基本学会                      |
| 第 30 轮 | ~75-80% | 收敛                          |

### 什么时候可以切换到阶段二？

**连续 2-3 轮准确率不再明显上升**，且达到 ≥70% 即可切换。不需要等到 80%。

### 产物

`weights\stage1_oxford.pth` — 包含 backbone + embedding 层 + 分类头的完整权重

---

## 五、阶段二：images.cv 狗鼻纹数据集

### 目标

用专门的狗鼻纹数据集 fine-tune，学到鼻纹的细粒度特征。

### 命令（单行，沿用阶段一的权重）

```powershell
python src/scripts/train_stage1.py --data "D:\ai-server\ai-service\dog_nose\data\train" --epochs 30 --batch 32 --lr 0.001 --embed-dim 512 --output "weights\stage2_dognose.pth" --resume "weights\stage1_oxford.pth"
```

**关键参数说明：**

| 参数       | 值                           | 说明                                                                   |
| ---------- | ---------------------------- | ---------------------------------------------------------------------- |
| `--resume` | `weights\stage1_oxford.pth`  | **加载阶段一的权重**，backbone 和 embedding 层保留，只重新初始化分类头 |
| `--lr`     | 0.001                        | 比阶段一小10倍，因为已经在很好基础上 fine-tune                         |
| `--output` | `weights\stage2_dognose.pth` | 新产物                                                                 |

### 切换逻辑解释

```
阶段一权重（Oxford Pets，37类）
        ↓
加载 backbone + embedding 层（保留）
        ↓
丢弃旧的分类头（37类输出），换成新的（假设 N 类）
        ↓
用狗鼻纹数据训练新的分类头 + 微调 embedding
```

这就是 `--resume` 的作用：不是从零开始，而是从一个更好的起点开始。

### 什么时候可以切换到阶段三？

准确率 ≥70% 即可切换。如果数据量少（<1000张），可能很难达到 70%，达到一个稳定的高点就行。

### 产物

`weights\stage2_dognose.pth`

---

## 六、阶段三：Stanford Dogs（可选，跳过也可以）

### 目标

用 Stanford Dogs（120类）的更多数据进一步增强模型。

### 命令（单行，沿用阶段二的权重）

```powershell

```

### 产物

`weights\stage3_stanford.pth` — 最终模型

## 七、断点续训：中途停止或继续训练

### 情况1：训练到一半想停止

随时按 `Ctrl+C`，权重文件不会丢失（只保存最佳模型）。

### 情况2：想继续训练同一个模型

```powershell
python src/scripts/train_stage1.py --data "D:\ai-server\ai-service\oxford_pets_split\train" --epochs 30 --batch 32 --lr 0.01 --embed-dim 512 --output "weights\stage1_oxford.pth" --resume "weights\stage1_oxford.pth"
```

加上 `--resume "weights\stage1_oxford.pth"` 会在现有权重基础上继续训练（不用手动改参数）。

### 情况3：发现参数设错了，想重新来

直接改参数重新运行即可，权重文件会被覆盖。

## 八、常见问题

### Q：报错 "out of memory"

A：8GB 显存用 `--batch 32` 刚好，如果爆了改成 `--batch 16`

### Q：准确率一直只有 20-30% 不涨

A：检查数据路径是否正确、图片是否清晰、拉取最新代码 `git pull`

### Q：换数据集后准确率反而低了

A：正常。新数据集类别数/分布不同，分类头需要重新学习。继续训练会慢慢回升。

### Q：各个阶段的学习率为什么不同？

A：阶段一从头训练分类头，可以用较大的学习率（0.01）；阶段二/三在已有权重上微调，学习率要小（0.001）避免破坏已学到的特征。

### Q：阶段一跑到一半可以换成阶段二吗？

A：可以。只要阶段一准确率趋势正常（逐步上升），随时可以切换数据集。用 `--resume "weights\stage1_oxford.pth"` 加载阶段一的权重开始阶段二。

### Q：训练要多久？

A：每个阶段 30 轮约 10-15 分钟（RTX 4060 GPU）。总共最多 45 分钟。

### Q：最终模型用哪个？

A：最后一个阶段的权重文件（如 `weights\stage2_dognose.pth` 或 `weights\stage3_stanford.pth`）。

## 九、训练好的模型怎么用（部署到 API 服务）

训练产出的 `.pth` 文件交给 AI 服务负责人，放到 `weights/` 目录即可。

**不需要改训练代码**，只需改一行 API 加载代码：

`src/api/extract.py` 第21行：

```python
# 改这一行，加载你的权重文件
_model = load_model(weights_path="weights/stage1_oxford.pth", embedding_dim=512)
```

权重来源：
| 阶段 | 权重文件 | 用途 |
|------|----------|------|
| 阶段一 | `weights/stage1_oxford.pth` | Oxford Pets 预训练（已可用） |
| 阶段二 | `weights/stage2_dognose.pth` | 狗鼻纹微调（待队友训练） |
| 阶段三 | `weights/stage3_stanford.pth` | Stanford Dogs 细粒度（最终模型） |

**部署步骤：**
1. 队友把训练好的 `.pth` 文件发给你
2. 放到 `F:\swcup2026\ai-service\weights\`
3. 改 `src/api/extract.py` 第21行的 `weights_path`
4. 重启 `uvicorn src.main:app`

**验证是否生效：** 运行 `python test_weight_load.py`，看到所有 `✅` 即为正常。
