## 一、train_breed.py — 品种分类训练

### 用途

用 Oxford Pets（37类）+ Stanford Dogs（120类）联合训练一个品种分类模型，输出品种分类结果。

### 命令行参数

```
--data-oxford     Oxford Pets train 目录（默认 oxford_pets_split/train）
--data-stanford   Stanford Dogs 根目录（默认 Stanford_Dogs/）
--epochs          训练轮数（默认 20）
--batch           batch size（默认 32）
--lr              学习率（默认 0.001）
--embed-dim       embedding 维度（默认 512）
--num-classes     输出类别总数（默认 157 = 37+120，guide 中定义为 157）
--output          权重保存路径（默认 weights/breed_classifier.pth）
--device          设备（默认 cuda 或 cpu）
--resume          断点续训路径（可选）
```

### 数据处理逻辑

1. **Oxford Pets**：直接遍历 `oxford_pets_split/train/{class}/` 下的图片，class 名称作为 label
2. **Stanford Dogs**：遍历 `Stanford_Dogs/{n020xxxxx-ClassName}/` 下的图片，与 Oxford Pets 合并成同一份训练集
3. **标签合并**：给 Oxford Pets 的 37 类分配标签 0~36，Stanford Dogs 的 120 类分配标签 37~156（不合并重复狗种，guide 明确说明"同一张图标记为不同类别没关系"）
4. **数据增强**：RandomHorizontalFlip、RandomRotation(±15°)、ColorJitter(brightness=0.2, contrast=0.2)、ImageNet 归一化
5. **图片尺寸**：224×224

### 模型结构

```
MobileNetV2 backbone（ImageNet 预训练权重）
    ↓
AdaptiveAvgPool2d
    ↓
Flatten → Linear(1280, 512)  ← 可学习的 embedding 层
    ↓
Linear(512, 157)             ← 品种分类头（157 类）
```

### 训练策略

- **阶段一**：冻结 backbone，只训 embedding 层 + 分类头（默认行为）
- **阶段二**：解冻最后 2 个卷积块，低学习率微调（`--no-freeze-backbone` 参数）
- **优化器**：Adam，学习率 `args.lr`
- **学习率调度**：CosineAnnealingLR
- **损失函数**：CrossEntropyLoss
- **只记录 train 准确率**（guide 中没有单独 val set，所以用 train acc 做验证）

### 输出

- 权重文件：`weights/breed_classifier.pth`
- checkpoint 包含：`state_dict`、`embedding_dim`、`num_classes`、`best_acc`
- 打印每个 epoch 的 loss 和 acc

### 预期指标

| 指标 | 目标 |
|------|------|
| Top-1 Accuracy | ≥ 85% |
| Top-3 Accuracy | ≥ 95% |

## 二、train_nose_metric.py — 鼻纹特征训练（ArcFace）

### 用途

用鼻纹数据集（6000只狗，每只4张图）训练度量学习模型，同一只狗的图片余弦相似度应高于不同狗的图片。

### 命令行参数

```
--data            鼻纹数据根目录（默认 dir_train/dir_train/{dog_id}/）
--epochs          训练轮数（默认 30）
--batch           batch size（默认 32）
--lr              学习率（默认 0.001）
--embed-dim       embedding 维度（默认 512）
--margin          ArcFace margin m（默认 0.5）
--scale           ArcFace scale s（默认 64）
--output          权重保存路径（默认 weights/nose_feature.pth）
--device          设备（默认 cuda 或 cpu）
--resume          断点续训路径（可选）
```

### 数据处理逻辑

1. **数据集结构**：`dir_train/dir_train/{dog_id}/{dog_id}__{uuid}.jpg`，6000 个文件夹
2. **不需要配对数据**：ArcFace Loss 会自动从同一文件夹构造正样本对，不同文件夹构造负样本对
3. **数据增强**：RandomHorizontalFlip、RandomRotation(±15°)、ColorJitter(brightness=0.2, contrast=0.2)、ImageNet 归一化
4. **图片尺寸**：224×224

### 模型结构

```
MobileNetV2 backbone（ImageNet 预训练权重）
    ↓
AdaptiveAvgPool2d
    ↓
Flatten → Linear(1280, 512)  ← embedding 层
    ↓
ArcFace Head: Linear(512, 6000) + margin-based softmax
```

**ArcFace 细节**：
- `scale = 64`，`margin = 0.5`（cos(mθ) 模式）
- 输入是 512-dim 归一化 embedding，输出 6000 类的 logit
- 特征与权重的角度空间间隔增大，提升区分度

### 训练策略

- **阶段一**（默认）：冻结 backbone，训练 embedding 层 + ArcFace 头，30 epochs
- **阶段二**（可选）：`--resume` 加载阶段一权重 + `--no-freeze-backbone`，低学习率 0.0001 微调 10 epochs
- **优化器**：Adam
- **损失函数**：ArcFace 自定义损失（联合优化 cosθ 和角度间隔）
- **阶段一只用 train set 评估**（没有 val set）

### 输出

- 权重文件：`weights/nose_feature.pth`
- checkpoint 包含：`state_dict`、`embedding_dim`、`num_classes`（=6000）、`best_cos_sim`（同狗余弦相似度）
- 每个 epoch 打印：loss、正样本对余弦相似度均值

### 预期指标

| 指标 | 目标 |
|------|------|
| 同狗鼻纹余弦相似度 | > 0.80 |
| 不同狗鼻纹余弦相似度 | < 0.50 |
| Recall@1 | ≥ 90% |

## 三、evaluate_breed.py — 品种分类评测

### 用途

在 Oxford Pets 的 test set（37类）上评测 `breed_classifier.pth` 的准确率。

### 命令行参数

```
--model            权重文件路径（必填）
--data             Oxford Pets test 目录（默认 oxford_pets_split/test）
--device           设备（默认 cuda 或 cpu）
```

### 评测逻辑

1. 加载模型权重（去掉分类头，用 embedding 层做特征提取）
2. 遍历 `oxford_pets_split/test/{class}/` 所有图片
3. **Top-1 Accuracy**：取 softmax 概率最大的类别，与真实标签比较
4. **Top-3 Accuracy**：概率前3名中有任一命中即算正确
5. 输出混淆矩阵摘要

### 输出格式

```
Top-1 Accuracy: 87.34%
Top-3 Accuracy: 96.12%
```

## 四、evaluate_nose.py — 鼻纹特征评测

### 用途

评测 `nose_feature.pth` 的度量学习质量：同狗余弦相似度 vs 不同狗余弦相似度，Recall@1。

### 命令行参数

```
--model            权重文件路径（必填）
--data             鼻纹数据目录（默认 dir_train/dir_train/）
--device           设备（默认 cuda 或 cpu）
```

### 评测逻辑

1. 加载模型，用 embedding 层提取所有图片的 512-dim 向量（**不做分类头**）
2. **同狗相似度**：同一文件夹（dog_id 相同）的图片两两配对，计算余弦相似度，取平均
3. **不同狗相似度**：不同文件夹的图片随机采样配对，计算余弦相似度，取平均
4. **Recall@1**：对每张图片，在所有图片中找最相似的另一张（不能是自己），看是否同狗

### 输出格式

```
Same-dog cosine similarity:    0.8734 (mean)
Different-dog cosine similarity: 0.3421 (mean)
Recall@1:                      92.34%
```

## 共用约定

- 所有脚本从 `src.scripts` 作为 module 入口（`python -m src.scripts.xxx`）
- `python -m src.scripts.train_breed --help` 能打印完整参数说明
- checkpoint 格式统一为 dict，包含 `state_dict`、`embedding_dim`、`num_classes` 及任务相关指标
- weights 目录为 `ai-service/weights/`
- 设备自动检测：有 cuda 用 cuda，没有用 cpu
