# 队员开发环境指南（前端/UI）

> 适用角色：队员（前端界面开发）
> 整理时间：2026-05-07
> 并行于 AI 训练环境搭建，可同时进行

---

## 一、必须安装（5项）

### 1. HBuilderX（IDE，推荐最新版）

UniApp 御用开发工具，支持 Vue3 项目一键创建、微信小程序真机预览。

| 项目 | 说明 |
|------|------|
| 下载地址 | https://www.dcloud.io/hbuilderx.html |
| 版本 | Windows x64 最新正式版 |
| 安装 | 解压即用，不需要安装到C盘 |

> HBuilderX 比 VSCode 更适合 UniApp 项目，有内置的模拟器和真机调试功能。

### 2. 微信开发者工具

| 项目 | 说明 |
|------|------|
| 下载地址 | https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html |
| 版本 | Windows x64稳定版 |
| 用途 | 预览和调试微信小程序（用户端+管理端） |

安装后在设置 → 安全 → 开启服务端口（HBuilderX 联动需要）。

### 3. Node.js（LTS 版本）

npm 包管理器，前端项目依赖管理。

| 项目 | 说明 |
|------|------|
| 下载地址 | https://nodejs.org/（选 LTS，不要 latest） |
| 验证 | 打开命令行输入 `node -v` 和 `npm -v` |
| 版本要求 | Node ≥ 16，npm ≥ 8 |

### 4. Git（版本控制）

| 项目 | 说明 |
|------|------|
| 下载地址 | https://git-scm.com/download/win |
| 版本 | Windows x64 |
| 验证 | 打开命令行输入 `git -v` |
| 用途 | 队长会建立 Git 仓库，队员 clone 到本地提交代码 |

> 学长学姐的参考项目也在 Git 上管理，先装好 Git。

### 5. Vue.js devtools（浏览器插件）

| 项目 | 说明 |
|------|------|
| 下载地址 | Chrome 扩展商店搜索 "Vue.js devtools" |
| 用途 | 调试 Vue3 组件状态，检查页面数据流 |
| 浏览器 | 推荐 Chrome / Edge |

## 二、推荐安装（可选，但建议装）

### 6. VSCode（代码编辑器）

HBuilderX 主要用来写页面，VSCode 适合写配置文件和做代码编辑。

| 项目 | 说明 |
|------|------|
| 下载地址 | https://code.visualstudio.com/ |
| 必装插件 | Vue - Official（语法高亮）、ESLint、Prettier |

### 7. Python 3.9+（本地运行 AI 服务）

| 项目 | 说明 |
|------|------|
| 下载地址 | https://www.python.org/downloads/ |
| 验证 | 打开命令行输入 `python -V` |
| 用途 | 本地运行 FastAPI AI 推理服务，队员可以独立测试前端对接 |

安装时勾选 **"Add Python to PATH"**。

## 三、参考项目下载

队长会把学姐的参考项目整理到仓库里，队员 clone 下来参考：

```
git clone <仓库地址>
```

参考项目结构（待队长整理后补充）：

```
├── pages/           ← 页面组件（直接参考UI模式）
├── components/      ← 可复用组件（登录框、卡片、分页）
├── static/          ← 静态资源
└── README.md         ← 项目说明
```

## 四、Git 协作流程（简单版）

```
1. 队长建立 Git 仓库，队员收到仓库地址
2. 队员 clone 到本地：git clone <仓库地址>
3. 创建自己的分支：git checkout -b feature/你的名字-页面名
4. 开发完提交：git add . → git commit -m "feat: 添加XX页面"
5. 推送到远程：git push origin feature/你的名字-页面名
6. 在 GitLab/GitHub 上提 Merge Request（MR）给队长审查
```

> 详细 Git 操作队长会在仓库建立后发文档。

## 五、环境验证清单

安装完成后，打开命令行依次验证：

```bash
# 1. Node.js
node -v
# 预期输出：v16.x.x 或更高

# 2. npm
npm -v
# 预期输出：8.x.x 或更高

# 3. Git
git -v
# 预期输出：git version 2.x.x

# 4. Python（可选）
python -V
# 预期输出：Python 3.9.x 或更高

# 5. HBuilderX
# 打开 HBuilderX → 新建项目 → 选 UniApp → 选 Vue3 → 看是否正常
```

## 六、第一天可以做的事（不需要等队长）

1. 安装以上 5 个软件（1小时内完成）
2. 注册 GitHub/GitLab 账号（如果有的话）
3. 下载学姐参考项目到本地，先跑起来看看结构
4. 看 UniApp 官方文档了解 Vue3 项目结构
5. 在 HBuilderX 里新建一个 UniApp + Vue3 空项目，看能不能跑通编译

## 七、常见问题

| 问题 | 解决 |
|------|------|
| HBuilderX 打开后提示"无法访问外网" | 检查代理设置，或者换国内镜像源 |
| 微信开发者工具打不开 | 用管理员权限运行，或检查是否被杀毒软件拦截 |
| npm install 很慢 | 切换淘宝镜像：`npm config set registry https://registry.npmmirror.com` |
| clone 代码报错 | 检查 Git 是否安装、SSH Key 是否配置 |
