# 实体：鼻纹特征

## 基本信息

> 鼻纹特征是动物身份识别的核心数据，存储 MobileNetV2 模型提取的 512 维特征向量。
> 每只动物可有多个鼻纹特征记录（不同角度、不同时间采集），但只有一个**主特征向量**用于比对。

## 数据结构

### 核心字段

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `vector_id` | UUID | ✅ | 特征向量唯一标识 | `v1a2b3c4-...` |
| `animal_id` | UUID | ✅ | 关联的动物记录 | `a1b2c3d4-...` |
| `feature_vector` | Array[Float] | ✅ | 512维 MobileNetV2 特征向量 | `[0.123, -0.456, ...]` |
| `vector_dimension` | Int | ✅ | 向量维度（固定 512） | `512` |
| `nose_photo_url` | String | ✅ | 原始鼻纹照片存储路径 | `/uploads/nose/xxx.jpg` |
| `landmark_data` | JSON | ❌ | 关键点标注（鼻框中心+鼻翼） | `{"center": {...}, "wings": [...]}` |
| `confidence_score` | Float | ❌ | 图片质量置信度（0-1） | `0.95` |
| `is_primary` | Boolean | ✅ | 是否为主特征向量 | `true` |
| `collection_angle` | String | ❌ | 采集角度：front / left / right / top | `front` |
| `created_at` | DateTime | ✅ | 采集时间 | `2026-05-04` |
| `model_version` | String | ✅ | 提取模型版本 | `mobilenet_v2_w4_v1.0` |
| `liveness_check_passed` | Boolean | ✅ | 活体检测是否通过 | `true` |

### 索引设计

```sql
-- 向量索引（使用 pgvector 或 Qdrant）
CREATE INDEX idx_nose_vector_ann ON nose_features
USING ivfflat (feature_vector vector_cosine_ops)
WITH (lists = 100);

-- 动物 ID 索引（快速查找某动物的所有特征）
CREATE INDEX idx_nose_vector_animal ON nose_features(animal_id);

-- 主特征索引
CREATE INDEX idx_nose_vector_primary ON nose_features(animal_id)
WHERE is_primary = true;
```

## 采集流程

```
用户上传鼻纹照片
        │
        ▼
  活体检测（RGB图像判断真实性）
        │ ✅ 通过
        ▼
  鼻纹区域裁剪 + 关键点标注
        │
        ▼
  MobileNetV2 特征提取（512维向量）
        │
        ▼
  存储至 nose_features 表
        │
        ▼
  写入向量数据库（Qdrant/Milvus）
```

---

## 与动物记录的关系

- **1:N**：一只动物可以有多个鼻纹特征（不同角度采集）
- **主特征**：每只动物有且只有一个 `is_primary = true` 的特征向量
- **比对策略**：新采集的特征与该动物的主特征进行比对
