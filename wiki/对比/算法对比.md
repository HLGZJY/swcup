# 算法对比

> 本页对比各图像相似度算法在本项目（AI 鼻纹救助系统）中的适用性。

## 快速对比表

| 算法 | 准确率 | 速度 | 资源消耗 | 适配本项目 | 推荐度 |
|------|--------|------|----------|------------|--------|
| **MobileNetV2 迁移学习** | ⭐⭐⭐⭐⭐ | 快 | GPU 推荐，CPU 可行 | 鼻纹特征提取 | ✅ 已选方案 |
| VGG16 迁移学习 | ⭐⭐⭐⭐ | 慢 | GPU 必须 | ~~替代为 MobileNetV2~~ | ❌ v1 方案已废弃 |
| CLIP 特征提取 | ⭐⭐⭐ | 中等 | GPU 推荐 | 语义辅助 | 🟡 可作辅助 |
| ResNet + 余弦 | ⭐⭐⭐ | 快 | CPU 可行 | 快速原型 | 🟡 可作 Baseline |
| 度量学习 (Triplet) | ⭐⭐⭐⭐⭐ | 中等 | GPU 推荐 | 精细化比对 | 🟡 未来优化方向 |
| pHash 感知哈希 | ⭐⭐ | 极快 | CPU | 四维度融合·图片维度 | ✅ 已选方案（20%权重） |
| SSIM 结构相似度 | ⭐⭐⭐ | 快 | CPU | 四维度融合·图片维度 | ✅ 已选方案（20%权重） |
| EfficientNet-B0 | ⭐⭐⭐⭐ | 中等 | GPU 推荐 | 备选 backbone | 🟡 精度不达标时替换 |

## 商业 API 调研结论

| API | 支持内容 | 成本 | 结论 |
|-----|---------|------|------|
| 百度AI动物识别 | 仅支持种类识别（猫/狗分类） | 免费额度 | ❌ 不支持个体识别，不满足需求 |
| 旷视Face++ | 鼻纹检测+比对 | 费用较高 | ❌ 成本不可控，商用不划算 |
| 腾讯云AI | 图像分析+动物识别 | 按量计费 | 参考，不作为主方案 |

**结论**：现有商业 API 无法满足"个体识别"需求，且成本不可控，**必须自训练轻量化模型**。

## 本项目最终选型

### ✅ 已选定方案

#### 1. MobileNetV2 迁移学习（核心：40% 权重）

**选定原因**：

- 轻量化，适合移动端部署（比赛要求可演示）
- 迁移学习减少对数据量的需求（2000张足够）
- 两阶段训练流程确保收敛和泛化
- CPU 可训练（i7+16GB 够用），8-12 小时训练时间

**训练流程**：

| 阶段 | 操作 | 学习率 | Epochs | 说明 |
|------|------|--------|--------|------|
| 阶段一 | 冻结 backbone，仅训练输出层 | 1e-3 | 5-10 | 快速收敛新层，早停条件：验证集连续5次无提升 |
| 阶段二 | 解冻最后2个卷积块，低学习率微调 | 1e-4 | 按需 | 数据增强：翻转/旋转/亮度/小角度畸变 |

**评测目标**：

| 阶段 | Accuracy 目标 | 说明 |
|------|---------------|------|
| W3 baseline | ≥ 70% | 验证集 Top-1 Accuracy |
| W4 优化后 | ≥ 85% | 数据增强 + 微调后 |
| 终极目标 | ≥ 90% | 充足数据+精细调优 |

#### 2. pHash / SSIM（辅助：20% 权重）

- 计算极快，CPU 可运行
- 与深度学习特征互补（全局 vs 局部）

#### 3. GPS 距离匹配（辅助：20% 权重）

- Haversine 公式计算距离，`S_location = max(0, 1-(d-500)/1000)`
- 500m内满分，1500m外权重归0

#### 4. 关键词重合度（辅助：20% 权重）

- Jaccard 关键词重合度（推荐）或 BM25（备选）

## 方案变更说明（v1 → v2）

| v1 方案 | v2 变更 | 变更原因 |
|---------|---------|----------|
| VGG16 迁移学习 | 改为 MobileNetV2 | 移动端推理更快，参数更少 |
| 纯鼻纹特征比对 | 改为四维度融合 | 提升准确率，减少误判 |
| INT8 量化/边缘部署 | 删除 | 初赛无需工程优化，8 周时间有限 |
| 兼容性测试/性能测试报告 | 删除 | 形式大于内容，聚焦核心交付 |
