# 四维度融合策略

## 核心要点

1. **定义**：综合四个维度的相似度信息，加权求和得到最终匹配得分，判定是否为同一只动物
2. **权重分配**：特征向量 40% + 位置 20% + 图片 20% + 文本 20%
3. **核心优势**：单一维度易受干扰，多维度融合可大幅提升准确率，减少误判
4. **排序输出**：返回 Top-N 匹配结果供用户确认

## 公式定义

```
综合得分 = 0.40 × S_vector     (鼻纹特征向量余弦相似度)
         + 0.20 × S_location  (位置距离权重)
         + 0.20 × S_image     (整图相似度)
         + 0.20 × S_text      (文本描述匹配度)
```

每个维度得分归一化到 [0, 1] 区间，最终得分越高表示匹配可能性越大。

## 各维度详解

### 维度一：鼻纹特征向量（40%）— 核心

**技术实现**：

- 输入：待比对图片的 128 维 MobileNetV2 特征向量
- 比对方式：余弦相似度 `cosine_similarity(V_new, V_db)`
- 特点：**最核心的判断依据**，权重最高
- 阈值规则：若 `S_vector ≥ 0.92`，无论其他维度如何，直接标记重复（鼻纹置信度高）

### 维度二：位置（20%）

**技术实现**：

- 输入：用户上报时的 GPS 坐标 vs 数据库中已知位置（**自动获取，非手动选择，精度 ≤ 10m**）
- 计算方式：Haversine 公式计算地球表面两点间距离
- **精确权重公式**（产品描述 v1.5）：

```
S_location = max(0, 1 - (distance_m - 500) / 1000)
```

| 距离 | S_location |
|------|-----------|
| ≤ 500m | 1.0（满分） |
| 500m–1500m | 线性衰减 |
| ≥ 1500m | 0（权重为0） |
| ≥ 5000m | 权重强制归0（超出动物正常活动范围） |

- 注意事项：猫 vs 狗的活动半径不同，权重策略可差异化

### 维度三：图片整体（20%）

**技术实现**：

- **pHash（感知哈希）**：
  - 将图片缩放到 32x32 → 灰度图 → DCT 变换 → 生成 64 位哈希
  - 计算两图哈希的汉明距离 → 转换为 [0,1] 得分

- **SSIM（结构相似度）**：
  - 考虑亮度、对比度、结构三个维度
  - 适合检测图片内容相似性

- 特点：**辅助验证**，对整图相似性敏感

### 维度四：文本描述（20%）

**技术实现**：

- **Jaccard 关键词重合度**（推荐，快速实现）：
  ```
  S_text = |关键词集合_A ∩ 关键词集合_B| / |关键词集合_A ∪ 关键词集合_B|
  ```
  关键词来源：品种、颜色、性别、特殊标记

- **BM25**（备选，更精确）：
  - 对品种/颜色/性别/特征字段构建倒排索引
  - 计算查询与档案的 BM25 得分

- 特点：**辅助参考**，在向量相似度处于灰色地带时（0.75-0.88）尤为重要

## 置信度分级

| 综合得分 | 置信度 | 用户行为 | 展示内容 |
|----------|--------|----------|----------|
| **≥ 0.88** | **确认重复** | 弹窗警告，禁止直接发布（可选择"确认是同只动物，关联"或"仍要发布"） | 匹配项的照片+定位+相似度明细 |
| **0.75–0.88** | **疑似重复** | 弹窗提示，用户可选择"关联"或"忽略并发布" | 展示 Top-3 疑似匹配项 |
| **< 0.75** | **无匹配** | 正常发布流程，无特殊提示 | — |

> ⚠️ 阈值通过验证集实测校准，非拍脑袋决定（详见下节"阈值校准流程"）

## 置信度可视化（用户端）

用户可在"我的留言"中查看 AI 分析结果：

```
鼻纹清晰度：92%（优秀）/ 68%（一般，建议重拍）
与库中已有鼻纹的匹配情况：暂无匹配 / 发现 1 个疑似匹配
```

→ 帮助用户理解 AI 工作原理，增加产品信任度

## 输出示例

```
检测结果：
├── AI特征相似度：95%
├── 定位距离：200m
├── 图片相似度：78%
├── 文本相似度：65%
└── 综合评分：高度疑似重复（92/100）
```

## 阈值校准流程（W3 阶段）

> ⚠️ 初定 0.88 / 0.75 作为基准，必须通过 ROC 曲线实测校准后作为最终阈值。

**流程**：

1. 用验证集（200组正样本 + 200组负样本）跑全部测试
2. 绘制 ROC 曲线
3. 计算不同阈值下的 Precision / Recall / F1
4. 取 **Youden's J Index** 最优值作为最终阈值
5. 输出 W3 评测报告存档

**预期结果**：

| 指标 | 目标 |
|------|------|
| Accuracy | ≥ 80% |
| Recall | ≥ 80% |
| F1 | ≥ 80% |
| 误报率 | < 5% |

## 边界情况

| 场景 | 系统行为 |
|------|----------|
| Top-1 与 Top-2 分数接近（0.91 vs 0.89） | 返回 Top-3 全部展示，提示"有多个疑似匹配，请人工确认" |
| GPS 定位明显异常（跨省） | 提示"定位异常，请检查位置权限"，拒绝发布 |
| AI 向量 ≥ 0.92 但其他维度全为 0 | 直接判定重复（鼻纹置信度高优先） |
| 同城同品种短时间（72h）高相似度 | 优先提示重复 |
