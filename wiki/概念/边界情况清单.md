# 边界情况清单

> 本页记录系统在各种边界场景下的行为规则，作为开发和测试的依据。

---

## AI 检测边界情况

| 场景 | 系统行为 |
|------|----------|
| 用户上传狗的照片，但文字描述写"猫" | AI 向量识别为狗，权重更高；提示"检测到您上传的是狗，请确认品种" |
| AI Top-1 与 Top-2 分数接近（0.91 vs 0.89） | 返回 Top-3 全部展示，提示"有多个疑似匹配，请人工确认"，不做自动判定 |
| GPS 定位明显异常（跨省） | 提示"定位异常，请检查位置权限"，拒绝发布 |
| AI 向量相似度 ≥ 0.92 但其他维度全为 0 | 直接判定重复（鼻纹置信度高，优先于其他维度） |
| 同城同品种短时间内（72h 内）高相似度 | 优先提示重复 |
| 图片审核 API 免费额度用完 | 切换备用 API（预接入 2 家），API Key 存于配置，切换不涉及代码修改 |
| 审核 API 超时/失败 | 降级为本地敏感词预检，图片先存草稿，审核通过后再发布 |
| 图片质量不合格（分辨率低/鼻部区域<1/4） | 弹出提示"鼻部区域不够清晰，请重拍"，不提交 |

## 认领与状态边界情况

| 场景 | 系统行为 |
|------|----------|
| 多用户同时声称对同一只动物的所有权 | 先到先得；后到者标记"冲突，人工审核"，管理员介入 |
| 动物走丢 1 个月后找回，用户忘记关闭留言 | 90 天超时自动改为"超时未匹配"，用户可选择重发或关闭 |
| 管理员删除留言后，原主人希望恢复 | 不支持恢复；提示"请重新发布" |

---

## 用户行为风控边界情况

| 规则 | 触发条件 | 系统行为 |
|------|----------|----------|
| 发布频率限制 | 同一用户 5 分钟内发布超过 3 条 | 第 4 条开始限流，弹出验证码 |
| 同一设备 24 小时限制 | 同一设备 24 小时内发布超过 5 条 | 需人机验证，验证通过后可发布 |
| 图片去重 | 用户上传的照片哈希值与库中已有相同 | 拒绝发布，提示"该照片已在系统中存在" |
| 必填文字描述 | 留言文字描述为空 | 拒绝发布，提示"请填写动物描述" |
| 同一用户发布多条几乎相同留言 | 疑似刷屏 | 触发频率限制，第 3 条起要求图形验证码 |

## 内容审核规则

| 审核对象 | 审核方式 | 违规处理 |
|---------|---------|----------|
| 图片 | 调用第三方图片审核 API（腾讯云/阿里云） | 不通过：拒绝发布，提示"图片不符合要求" |
| 图片审核接口超时/失败 | 降级为本地敏感词预检，图片先存草稿 | 草稿状态，审核通过后再发布 |
| 文字描述 | 本地敏感词库 + 第三方文本审核 | 不通过：拒绝发布，提示"描述包含敏感词" |

---

## 违规处理机制

| 违规次数 | 处理方式 |
|---------|----------|
| 首次 | 管理员人工警告 |
| 二次 | 禁止发布 7 天 |
| 三次 | 账号封禁，IP 列入黑名单 |

---

## 举报机制

- 任意用户可举报他人的留言（选择举报原因：虚假信息 / 侵犯隐私 / 恶意骚扰 / 其他）
- 被举报留言对其他用户临时隐藏，等待管理员审核
- 管理员审核结果：举报成立 → 删除留言；举报不成立 → 恢复展示

---

## 数据隐私边界

| 场景 | 规则 |
|------|------|
| GPS 精确坐标公开 | 用户精确坐标不对外公开，展示时模糊至 500m 范围半径 |
| 位置不可见设置 | 用户可设置留言为"位置不可见"（管理员可见，救助者不可见） |
| 动物保护协会可见范围 | 可见统计数据，不可见精确位置 |
| 留言删除后数据保留 | 鼻纹特征向量保留（脱敏后不关联个人身份，仅用于模型改进和统计） |

## 图片采集规范（边界）

| 项目 | 规格 | 边界处理 |
|------|------|----------|
| 单张大小 | ≥ 200KB，≤ 20MB | 超出范围拒绝上传 |
| 分辨率 | 宽度 ≥ 640px，高度 ≥ 480px | 不合格拒绝，提示重拍 |
| 鼻部区域占比 | 图片中鼻部不得小于整图 1/4 | 不合格拒绝，提示重拍 |
| 最少上传数量 | 每条留言至少 2 张不同角度照片 | 少于 2 张禁止发布 |
| 支持格式 | JPG / JPEG / PNG | 其他格式拒绝 |

- 兽医 / 宠物店导流
- 社交关注 / 粉丝系统
- 用户头像和个人主页
- 短信 / 电话等隐私联系方式暴露
- 跨平台数据互通
- 线下救助站管理功能
- 志愿者招募和管理系统
