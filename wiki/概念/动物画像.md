# 动物画像

## 核心要点

1. **定义**：从动物照片和描述中提取的结构化特征集合，用于描述和区分不同动物
2. **组成**：外观特征 + 位置特征 + 时间特征 + 行为特征
3. **用途**：构建特征向量，支持相似度计算和重复检测
4. **更新**：动物画像随时间推移可能变化（如毛发颜色变化、伤口愈合）

## 特征维度

### 外观特征（核心）

| 维度 | 描述 | 可提取方式 |
|------|------|------------|
| 品种 | 猫/狗/其他，大类品种 | 用户填写 + AI 分类 |
| 毛色 | 主要颜色、图案（纯色/斑点/条纹） | AI 图像分析 |
| 体型 | 胖/中等/瘦 | 图像估算 |
| 年龄段 | 幼年/成年/老年 | 用户填写 + 外观估计 |
| 性别 | 公/母/未知 | 用户填写 |
| 特殊标记 | 白斑、伤疤、项圈 | 图像分析 + 用户标注 |
| 面部特征 | 眼神、耳朵形状 | 图像分析（高级） |

### 位置特征

| 维度 | 描述 |
|------|------|
| 发现位置 | 经纬度、地址 |
| 发现地点类型 | 公园/街道/小区/救助站 |
| 地理围栏 | 是否在已知活动区域 |

### 时间特征

| 维度 | 描述 |
|------|------|
| 首次发现时间 | 第一次被记录的时间 |
| 最后出现时间 | 最近一次被记录的时间 |
| 上报频率 | 在某区域的出现频率 |

### 行为特征（可选）

| 维度 | 描述 |
|------|------|
| 亲人程度 | 亲人/怕人/中立 |
| 健康状况 | 健康/受伤/生病 |
| 是否绝育 | 已绝育/未绝育/未知 |

## 特征向量构建

```
动物画像向量 = [外观特征向量] + [位置特征编码] + [时间特征编码]
```

- **外观特征向量**：由图像模型（如 CLIP、ResNet）提取，维度 128-2048
- **位置特征**：GeoHash 编码 + 行政区划编码
- **时间特征**：季节编码 + 距今天数
