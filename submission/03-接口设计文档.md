## 1. 概述

本项目接口分两层：

- **外层**：NestJS 11.x 提供的 REST API（基线 #3，40 个端点），对外服务微信小程序与后台管理端
- **内层**：FastAPI 0.109 提供的 AI 推理服务（基线 #5，4 个端点），仅 NestJS 后端调用，不直接对外

所有 REST API 通过 `/api/v1/*`（部分支持 `/api/v2/*`）的 URI 版本控制暴露，统一 JWT 鉴权（基线 #18，Header `Authorization: Bearer <token>`），数据格式为 JSON，请求体最大 10MB（`backend/src/main.ts:22`）。

调用方：
- `miniapp-user`（用户端 12 个页面）
- `miniapp-admin`（管理端 5 个页面）
- `ai-service`（仅由后端 `nose.service.ts`、`matching.service.ts` 调用，不直连小程序）

## 2. 统一约定

### 2.1 响应格式

所有响应经 `backend/src/common/interceptors/transform.interceptor.ts` 包装：

```json
{ "code": 0, "message": "success", "data": { ... } }
```

- `code = 0` 表示成功，其他值参考 HTTP 状态码
- `data` 在错误时为 `null`
- 成功时 `message = "success"`

### 2.2 错误格式

`HttpExceptionFilter`（`backend/src/common/filters/http-exception.filter.ts:5-23`）：

```json
{ "code": 401, "message": "未登录", "data": null }
```

### 2.3 鉴权机制

`JwtAuthGuard`（`backend/src/common/guards/jwt-auth.guard.ts:7-26`）：
- 控制器默认要求登录
- 标记 `@Public()` 装饰器的方法可匿名访问
- `RolesGuard` + `@Roles('admin')` 实现角色权限

### 2.4 Swagger

`http://localhost:3000/api-docs` 可见所有接口文档（`backend/src/main.ts:32-39`）。

## 6. 鼻纹 AI 模块（3 接口，全部 `@Public`）

**来源**：`backend/src/nose/nose.controller.ts:15-34`

### 6.1 POST /api/v1/nose/collect

- **说明**：采集鼻纹 → 调 AI 提向量 → 在库内查找最相似动物
- **认证**：否（`@Public`）
- **请求**：
  ```json
  {
    "nose_photo": "data:image/jpeg;base64,...",
    "body_photo_url": "/static/uploads/body_xxx.jpg",
    "species": "dog",
    "location_lat": 39.9087,
    "location_lng": 116.3975
  }
  ```
- **响应**：
  ```json
  {
    "code": 0, "message": "success", "data": {
      "vector_id": "uuid",
      "confidence_score": 0.92,
      "liveness_passed": true,
      "is_duplicate": true,
      "matched_animal_id": "uuid-动物ID",
      "similarity": 0.91,
      "next_action": "ask_claim_or_new"
    }
  }
  ```
- **后端实现**：`backend/src/nose/nose.service.ts:163-256`
- **5 种 next_action**（基线 #15）：
  - `ask_claim_or_new` — 主链路匹配到（similarity ≥ 0.88），提示认领或新建
  - `ask_claim_existing` — 孤儿鼻纹已被人补建档
  - `ask_link_or_new` — 孤儿鼻纹（animal_id=null），提示关联或新建
  - `ask_user_create` — 无任何匹配，引导去结果页确认是否建档
  - `match_found` — compare 流程中 fusion ≥ 0.88 自动确认
- **错误码**：400（缺照片/坐标 0,0）

### 6.2 POST /api/v1/nose/compare

- **说明**：拿已有 vector_id 重新比对（前端重新计算用）
- **认证**：否
- **请求**：`{ "vector_id": "uuid", "species": "dog", "location_lat": 39.9, "location_lng": 116.4, "breed": "柴犬", "color": "黄" }`
- **响应**：
  ```json
  {
    "code": 0, "message": "success", "data": {
      "total": 5,
      "results": [{
        "animal_id": "uuid",
        "vector_id": "uuid",
        "fusion_score": 0.88,
        "vector_similarity": 0.91,
        "gps_distance_m": 230,
        "gps_similarity": 1.0,
        "text_match_rate": 0.85,
        "image_similarity": 0,
        "is_recommended": true,
        "is_orphan": false,
        "animal": { "animal_id": "uuid", "breed": "柴犬", ... },
        "nose_feature": { "vector_id": "uuid", "confidence_score": 0.92 }
      }],
      "threshold_confirmed": 0.88,
      "threshold_suspected": 0.75,
      "next_action": "match_found"
    }
  }
  ```
- **后端实现**：`backend/src/nose/nose.service.ts:258-431`
- **3 维融合公式**（基线 #8）：
  ```
  fusion = 0.5 × vector_similarity
        + 0.3 × gps_similarity
        + 0.2 × text_match_rate
  ```
  钳制到 [0, 1]

## 11. AI 服务 FastAPI（4 端点，内部）

**说明**：仅 NestJS 后端调用，不对外暴露。基线 #14。

### 11.1 POST /extract/feature

- **说明**：输入 base64 图片，输出 512 维 Float32 特征向量（已 L2 归一化）
- **请求**：`{ "image": "base64_string" }`
- **响应**：`{ "vector": [0.123, -0.456, ...], "embedding_dim": 512 }`
- **后端实现**：`ai-service/src/api/extract.py:57-72`
- **模型**：`ResNet50_512d`（`ai-service/src/models/mobilenet.py:74-109`）
- **权重**：`weights/nose_v3_sgd.pth`（98MB，2026-05-30）

### 11.2 POST /compare/vector

- **说明**：两个向量比对，返回余弦相似度 + L2 距离
- **请求**：`{ "vector_a": [...512 floats], "vector_b": [...512 floats] }`
- **响应**：`{ "cosine_similarity": 0.91, "l2_distance": 0.34 }`
- **后端实现**：`ai-service/src/api/compare.py:22-36` + `utils/vector.py`

### 11.3 POST /detect/liveness

- **说明**：图像质量检测（**注意：仅是质量评估，不是真正的活体**）
- **请求**：`{ "image": "base64_string" }`
- **响应**：
  ```json
  {
    "liveness_pass": true,
    "reason": "Image quality OK",
    "blur_score": 87.3,
    "brightness": 128.5
  }
  ```
- **后端实现**：`ai-service/src/api/detect.py:23-67`
- **阈值**（`detect.py:43-45`）：
  - `BLUR_THRESHOLD = 50.0`（Laplacian 方差，越大越清晰）
  - `BRIGHTNESS_MIN = 30.0`、`BRIGHTNESS_MAX = 220.0`（HSV V 通道）

### 11.4 POST /classify/breed

- **说明**：全身照 → 37 品种分类 + top-3
- **请求**：`{ "image": "base64_string" }`
- **响应**：
