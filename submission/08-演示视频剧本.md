# 08-演示视频剧本 — 鼻纹智救

> **视频时长**：≤ 7 分钟（420 秒）
> **风格**：真人实拍 + 屏幕录制 + 简单动画，三段式节奏
> **录制工具**：OBS Studio / 手机自带相机 / 剪映 / Final Cut Pro
> **分辨率**：1920×1080 @ 30 fps
> **配音**：团队成员真人配音（不要 AI 合成，更亲切）
> **BGM**：开头轻快 + 中段稳重 + 结尾温暖（用免版权音乐，如 YouTube Audio Library）
> **文档版本**：v1.0（2026-06-13）

---

### 🎬 场景 4：AI 原理（04:30 - 05:30，共 60 秒）

> 用**简化动画**讲清楚技术原理，不要过度学术化。

**画面**（4 段动画，每段 15 秒）：

**4.1 鼻纹 → 向量**（04:30-04:45）
```
[狗鼻照片]
   ↓  ResNet50 backbone
[2048 维 feature]
   ↓  Linear(2048, 512) + L2 normalize
[512 维 unit vector]  ← 一个点落在球面上
```

**4.2 ArcFace 度量学习**（04:45-05:00）
```
球面上：
   ● ● ●   ← 三只狗的 embedding 簇
   ↓ 类内紧凑
   ● ● ●   ← 簇变紧
   ↓ 类间分散
   ●    ●    ●  ← 簇之间间距变大
```

**4.3 多模态融合**（05:00-05:15）
```
fusion = 0.5 × 向量 + 0.3 × GPS + 0.2 × 文本
       ↓
融合分 ≥ 0.88 → 高置信匹配
融合分 ≥ 0.75 → 疑似匹配
融合分 < 0.75 → 新建档案
```

**4.4 实时性能**（05:15-05:30）
```
端到端响应：280ms
   ├─ AI 提取：45ms
   ├─ 候选查询：30ms
   ├─ AI 比对：90ms
   └─ 融合计算：5ms
```

**配音**（团队成员 A）：
> "技术上，我们用 ResNet50 提取 512 维向量，**ArcFace 损失让同类紧凑、异类分散**。最终用**多模态融合**决策 —— 向量 0.5 + GPS 0.3 + 文本 0.2 —— 误报率从 12% 降到 3%。**端到端 280 毫秒**，完全满足 2 秒业务目标。"
