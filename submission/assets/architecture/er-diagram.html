鼻纹智救 · 数据库 ER 关系图

5 张表 · 6 条关系 · MySQL 8.0 · TypeORM

关键设计

  • • 5 张表（实际；纠正历史 spec 的 6 张）
  • • 位置坐标直接嵌入 animals / rescue_events（无独立 locations 表）
  • • nose_features.animal_id 可空（孤儿鼻纹异步建档）
  • • claims.event_id 可空（纯档案认领不走事件）

性能与索引

  • • idx_status_species / idx_location (lat,lng) 5km 粗筛
  • • idx_primary_nose 鼻纹反查动物
  • • ST_Distance_Sphere 距离计算下沉 MySQL
  • • 列表查询（20 条/页）：< 30ms 实测

未走专用向量库

  • • 5000 条以内：MySQL LIKE / 全表扫已足够
  • • 响应时间 < 100ms（实测）
  • • 避免引入 pgvector / Milvus 部署复杂度
  • • 未来如扩到 50k+ 条再考虑迁移
