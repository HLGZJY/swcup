> 日期：2026-05-21

## 1. 事件模块现状

### 1.1 相关页面

| 页面 | 文件 | 职责 |
|------|------|------|
| 审核中心 | `pages/admin/audit/index.vue` | 处理 `pending` 状态事件的唯一入口 |
| 事件管理列表 | `pages/events/index.vue` | 查看所有事件（只读列表） |
| 事件详情页 | `pages/events/detail/index.vue` | 只读详情展示 |

### 1.2 事件状态流转

```
用户上报 → POST /api/events → status: pending
                ↓
        AI 融合判断
            ↓
    fusion_score ≥ 0.75 → 自动创建 animal 档案
    fusion_score < 0.75 → 不建档，status 仍为 pending
```

### 1.3 管理员操作（审核中心）

| 操作 | 接口 | 数据变更 |
|------|------|----------|
| 确认重复 | PUT /admin/events/:id/confirm | status → 'duplicated', is_duplicate → true |
| 驳回事件 | PUT /admin/events/:id/reject | status → 'rejected' |
| AI处理 | POST /admin/events/:id/process | status → 'processing' → 'identified' + 填充 species/breed |

**注意：** 管理员确认重复**不会**自动创建动物档案，档案在用户上报时已经可能自动创建。

## 2. 各页面职责边界

### 2.1 审核中心（唯一操作入口）

- **职责：** 处理 `pending` 状态事件，执行确认/驳回/AI处理操作
- **只负责待处理事件，不做详情展示**
- 管理员操作完毕后，事件离开 `pending` 状态，不再出现在审核中心

### 2.2 事件列表页（事件库）

- **职责：** 展示全部事件（所有状态），按状态筛选
- **只读**，点击卡片跳转到详情页
- 筛选 tabs：全部 / 待处理 / 已确认 / 已完成

### 2.3 事件详情页（只读展示）

- **职责：** 展示事件的完整信息，供管理员回顾已处理事件
- **无操作能力**，不放置确认/驳回按钮（操作保留在审核中心）
- 已处理事件的详情 → 审核中心没有这个入口 → 从事件列表进入详情页

---

## 3. 事件详情页内容清单

| 信息项 | 来源 | 说明 |
|--------|------|------|
| 基本信息 | 后端 GET /admin/events/:id | 事件类型、状态、描述 |
| 上报人 | 后端 | reporter_id |
| 位置信息 | 后端 | address, location_lat/lng（可调起地图） |
| 发生时间 | 后端 | occurred_at |
| 关联动物 | 后端 animal_id | 有则显示跳转入口 |
| 融合得分 | 后端 fusion_score | AI 比对结果 |
| 时间记录 | 后端 | 创建时间、发生时间 |

---

## 4. 缺口记录（暂不实现）

管理员在确认识别成功后（AI处理），如果该事件在用户上报时 fusion_score < 0.75 导致没有自动建档，管理员**无法通过界面补建档案**。

当前只有 `POST /admin/animals` 接口可以手动创建档案，但管理端没有暴露这个入口。如需实现，作为后续需求处理。
