## 3. 关键验证 Checklist

### 3.1 状态覆盖(10 只动物)

- [ ] claimed 待认领 2 只(A7/A10)
- [ ] archived 已归档 1 只(S10 后 A7)

### 3.2 位置策略
- [ ] A1+A2 同区(~80m)**触发**自动合并
- [ ] A5+A6 同区(~100m)**触发**自动合并
- [ ] A1+A9 跨物种同位置**不**合并
- [ ] A3/A4/A7/A8/A10 跨区**不**合并

- [ ] 跨物种不合并(物种过滤生效)
- [ ] 状态流转 claimed → archived
