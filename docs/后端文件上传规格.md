# 后端文件上传规格说明

## 鼻纹采集图片上传

### 接口信息

| 项目 | 说明 |
|------|------|
| 接口路径 | `POST /nose/collect` |
| HTTP 方法 | POST |
| Content-Type | application/json（Base64 内嵌）或 multipart/form-data |

### 当前实现

后端当前采用 **Base64 内嵌 JSON** 方式接收图片，暂不支持传统 multipart 上传。

```
POST /nose/collect
Content-Type: application/json
```

```json
{
  "nose_photo": "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
  "species": "dog",
  "animal_id": null,
  "location_lat": 31.2304,
  "location_lng": 121.4737,
  "device_id": "device_001",
  "timestamp": "2026-05-13T12:00:00.000Z"
}
```

---

## 字段规格

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| nose_photo | string | 是 | Base64 编码的图片数据，格式：`data:image/jpeg;base64,<data>` 或纯 Base64 字符串 |
| species | string | 是 | 动物种类：`dog` / `cat` / 其他 |
| animal_id | string/null | 否 | 关联动物 ID，传 `null` 表示先采集后关联 |
| location_lat | number | 否 | 采集时 GPS 纬度（浮点数） |
| location_lng | number | 否 | 采集时 GPS 经度（浮点数） |
| device_id | string | 否 | 设备标识 |
| timestamp | string | 否 | ISO 8601 时间字符串 |

---

## 图片规格

| 项目 | 限制 |
|------|------|
| 最大文件大小 | 5 MB（Base64 后约 6.67 MB 的原始大小） |
| 支持格式 | JPEG、PNG、JPG |
| 编码方式 | Base64（UTF-8） |
| 最小分辨率 | 建议 256×256 像素以上 |
| 最大分辨率 | 无硬性限制，建议不超过 2048×2048 |

**注意**：如果 Base64 字符串超过 5 MB，请先在前端压缩图片（建议质量 0.8，Resize 到宽高不超过 1024px）。

---

## 活体检测要求

当前版本 **暂不强制要求活体检测**，但建议前端按以下规范拍照：

1. **拍摄距离**：鼻纹距镜头 10-20cm
2. **光线**：自然光或均匀补光，避免强光直射和阴影
3. **角度**：正对动物鼻部，水平拍摄
4. **数量**：至少拍摄 1 张，建议 2-3 张（用于后续比对）
5. **清晰度**：鼻纹纹理清晰可辨，不要糊焦

未来版本（如接入真实 AI 服务后）可能增加活体检测要求。

## multipart/form-data 上传（未来扩展）

如后续改用文件上传方式（multipart/form-data），规格如下：

```
POST /nose/collect
Content-Type: multipart/form-data
```

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | binary | 是 | 图片文件 |
| species | string | 是 | 动物种类 |
| animal_id | string | 否 | 关联动物 ID |
| location_lat | number | 否 | 纬度 |
| location_lng | number | 否 | 经度 |
| device_id | string | 否 | 设备标识 |
| timestamp | string | 否 | 时间 |

头部需要带 Authorization Bearer token。

## 鼻纹比对图片上传

同采集接口 `POST /nose/compare`，格式完全相同：

```json
{
  "nose_photo": "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
  "species": "dog",
  "animal_id": "42311cae-ae41-4ae0-b413-93672ca68f46",
  "location_lat": 31.2304,
  "location_lng": 121.4737
}
```

- **最大文件大小**：5 MB
- **格式**：JPEG/PNG/JPG
- **额外必填字段**：`animal_id`（比对目标，不能为 null）
