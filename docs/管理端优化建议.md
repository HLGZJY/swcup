## 一、代码级问题（需修复）

### 1.1 动物档案搜索功能无效（P1）

**文件**：`miniapp-admin/src/services/mock.js`

**问题描述**：`animals/index.vue` 第 86 行将 `keyword` 参数传给 `mockGetAnimals(params)`，但 `mock.js` 第 143-151 行的 `mockGetAnimals` **未实现 keyword 过滤逻辑**。用户输入搜索词后，列表不会按关键词筛选。

**当前代码**（mock.js）：
```js
export function mockGetAnimals(params = {}) {
  return new Promise(resolve => {
    setTimeout(() => {
      let list = [...mockAnimals]
      if (params.species) list = list.filter(a => a.species === params.species)
      if (params.status) list = list.filter(a => a.status === params.status)
      // ❌ 缺少 keyword 过滤
      resolve({ code: 0, data: { total: list.length, list } })
    }, 400)
  })
}
```

**修复方案**：参考 `users/index.vue` 第 62-68 行的本地过滤写法，补充 keyword 条件：

```js
if (params.keyword) {
  list = list.filter(a =>
    a.breed.includes(params.keyword) ||
    a.color.includes(params.keyword) ||
    a.address.includes(params.keyword)
  )
}
```

**验证方法**：在动物档案页搜索"柴犬"，应只返回柴犬记录。

### 1.2 动物档案分页逻辑错误（P1）

**文件**：`miniapp-admin/src/pages/animals/index.vue`

**问题描述**：`loadAnimals()` 函数没有翻页参数（无 page/offset），每次调用都覆盖数据而非累加。初始加载后 `hasMore` 计算为 `false`，导致第一页就显示"没有更多了"，无法触发翻页。

**当前代码**（第 80-94 行）：
```js
async function loadAnimals() {
  if (loading.value) return
  loading.value = true
  const params: any = {}
  if (currentStatus.value !== 'all') params.status = currentStatus.value
  if (keyword.value) params.keyword = keyword.value

  const res: any = await mockGetAnimals(params)
  if (res.code === 0) {
    animals.value = res.data.list        // ❌ 覆盖而非累加
    hasMore.value = res.data.total > animals.value.length
  }
  loading.value = false
}

function onLoadMore() {
  if (!hasMore.value) return
  loadAnimals()  // ❌ 再次加载第一页，无翻页参数
}
```

**修复方案**：

```js
const page = ref(1)
const pageSize = 10

async function loadAnimals(append = false) {
  if (loading.value) return
  loading.value = true

  if (!append) {
    page.value = 1
    animals.value = []
  }

  const params: any = { page: page.value, pageSize }
  if (currentStatus.value !== 'all') params.status = currentStatus.value
  if (keyword.value) params.keyword = keyword.value

  const res: any = await mockGetAnimals(params)
  if (res.code === 0) {
    if (append) {
      animals.value.push(...res.data.list)
    } else {
      animals.value = res.data.list
    }
    hasMore.value = res.data.total > animals.value.length
    if (hasMore.value) page.value++
  }
  loading.value = false
}

function onLoadMore() {
  if (!hasMore.value) return
  loadAnimals(true)  // 传入 append=true
}
```

**验证方法**：Mock 数据补充到 10+ 条，翻页加载后列表应累加而非覆盖。

## 三、交互体验问题

### 3.1 审核中心 Tab 切换忽略 URL 参数（P2）

**文件**：`miniapp-admin/src/pages/admin/audit/index.vue`

**问题描述**：从管理首页点击"待审核事件"或"待审核认领"入口时，通过 `uni.navigateTo` 跳转并携带 `type` 参数（`/pages/admin/audit/index?type=events` 或 `?type=claims`）。但 `audit/index.vue` 的 `onMounted` 未读取 `options.type` 初始化 `currentTab`，导致跳转后 Tab 默认停留在"事件审核"，而非预期的 Tab。

**修复方案**：

```js
onMounted(async () => {
  // 读取 URL 参数初始化 Tab
  const pages = getCurrentPages()
  const currentPage = pages[pages.length - 1]
  const options = (currentPage as any).options || {}
  if (options.type === 'claims') {
    currentTab.value = 'claims'
  }

  // 后续加载逻辑不变
  const [eRes, cRes] = await Promise.all([...])
})
```

**验证方法**：从管理首页点击"待审核认领"入口，跳转后应默认显示"认领审核"Tab。

## 四、功能缺失

### 4.1 用户管理缺少角色筛选（P3）

**文件**：`miniapp-admin/src/pages/users/index.vue`

**问题描述**：用户列表只有搜索框，缺少角色（普通用户 / 管理员 / 机构）筛选 tab，但 `mockUsers` 数据包含 `role` 字段。

**修复方案**：参考 `animals/index.vue` 的状态筛选（第 12-21 行），添加角色筛选 tab：

```vue
<view class="filter-tabs">
  <view
    v-for="tab in roleTabs"
    :key="tab.value"
    :class="['filter-tab', { active: currentRole === tab.value }]"
    @click="onFilterRole(tab.value)"
  >
    <text>{{ tab.label }}</text>
  </view>
</view>
```

```js
const roleTabs = [
  { label: '全部', value: 'all' },
  { label: '普通用户', value: 'user' },
  { label: '管理员', value: 'admin' },
  { label: '机构', value: 'org' }
]
const currentRole = ref('all')

function onFilterRole(role: string) {
  currentRole.value = role
  users.value = []
  loadUsers()
}
```
