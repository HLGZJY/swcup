## P0 — 影响核心流程（必改）

### P0-1：鼻纹采集缺少定位和描述参数
- **文件**：`src/pages/collect/index.vue` L232-235
- **问题**：已通过 `uni.getLocation()` 获取了 lat/lng，但没有传给 `mockNoseCollect()`
- **现状**：`mockNoseCollect({ nose_photo, species })`
- **应改为**：`mockNoseCollect({ nose_photo, species, location_lat, location_lng, description })`
- **影响**：比对接口依赖采集时传入的 lat/lng 参与四维度融合，缺失会导致 GPS 维度得分不准确

### P0-2：认领表单提交字段严重缺失
- **文件**：`src/pages/claim/index.vue` L180-183
- **问题**：提交只传 `{ animal_id, notes }`，缺少 event_id（必填）、real_name、phone、relation
- **影响**：后端无法完成认领流程，必改

## P1 — Mock 与接口文档不一致（应改）

### P1-1：mockLogin 请求参数不匹配
- **文件**：`src/services/mock.js` `mockLogin()` + `src/pages/login/index.vue` L136-140
- **现状**：前端传 `{ avatar, nickname, phone }`
- **文档规定**：应传 `{ code, nickname, avatar_url }`，其中 `code` 是微信 `wx.login()` 获得的 code
- **说明**：真实场景需先调 `wx.login()` 获取 code，不是直接传 avatar 路径；当前 mock 和页面代码都需要改

### P1-2：mockNoseCollect 签名缺少字段
- **文件**：`src/services/mock.js` `mockNoseCollect()`
- **现状**：只接收 `{ nose_photo, species }`
- **应改为**：支持 `{ nose_photo, species, location_lat, location_lng, description }`（与 P0-1 联动）

### P1-3：mockSubmitClaim 缺少 event_id
- **文件**：`src/services/mock.js` `mockSubmitClaim()`
- **现状**：只接收 `{ animal_id, notes }`
- **应改为**：`{ animal_id, event_id, notes }`（event_id 必填，与 P0-2 联动）
