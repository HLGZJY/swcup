## 二、后端就绪后，前端要做的事

### 2.1 创建 API 配置文件

在后端项目根目录创建 `services/api.js`（用户端）或相同路径（管理端），统一管理接口地址：

```javascript
// miniapp-user/src/services/api.js

// 后端接口基础地址
// 开发环境：换成你们实际的接口地址
const BASE_URL = 'http://localhost:3000/api'

// 通用请求封装
function request({
  url,
  method = 'GET',
  data,
  header = {}
}) {
  // 从本地存储读取 token
  const token = uni.getStorageSync('token')

  return new Promise((resolve, reject) => {
    uni.request({
      url: BASE_URL + url,
      method,
      data,
      header: {
        'Content-Type': 'application/json',
        'Authorization': token ? `Bearer ${token}` : '',
        ...header
      },
      success: (res) => {
        if (res.statusCode === 200 && res.data.code === 0) {
          resolve(res.data.data)
        } else if (res.statusCode === 401) {
          // Token 过期，清除登录态，跳转登录页
          uni.removeStorageSync('token')
          uni.removeStorageSync('user_info')
          uni.showToast({ title: '请重新登录', icon: 'none' })
          uni.reLaunch({ url: '/pages/login/index' })
          reject(new Error('未登录'))
        } else {
          uni.showToast({
            title: res.data.message || '请求失败',
            icon: 'none'
          })
          reject(new Error(res.data.message))
        }
      },
      fail: (err) => {
        uni.showToast({ title: '网络错误', icon: 'none' })
        reject(err)
      }
    })
  })
}

export { request, BASE_URL }
```

### 2.2 修改 mock.js 切换到真实 API

将 `mock.js` 中的所有函数改为调用 `request`，示例如下：

#### 用户端示例

```javascript
// miniapp-user/src/services/api.js

import { request } from './api.js'

// 获取动物列表
export function getAnimals(params = {}) {
  return request({
    url: '/animals',
    method: 'GET',
    data: params
  })
}

// 鼻纹采集
export function noseCollect(data) {
  return request({
    url: '/nose/collect',
    method: 'POST',
    data
  })
}

// 鼻纹比对
export function noseCompare(data) {
  return request({
    url: '/nose/compare',
    method: 'POST',
    data
  })
}

// 登录
export function login(data) {
  return request({
    url: '/auth/login',
    method: 'POST',
    data
  })
}

// 上报事件
export function reportEvent(data) {
  return request({
    url: '/events',
    method: 'POST',
    data
  })
}

// 提交认领
export function submitClaim(data) {
  return request({
    url: '/claims',
    method: 'POST',
    data
  })
}
```

#### 管理端示例

```javascript
// miniapp-admin/src/services/api.js

import { request } from './api.js'

export function getAdminStats() {
```

### 2.3 页面中替换 import

找到所有引用 mock 函数的页面，修改 import：

```javascript
// 原来的 Mock 引用
import { mockGetAnimals, mockNoseCompare } from '@/services/mock.js'

// 改为真实 API
import { getAnimals, noseCompare } from '@/services/api.js'
```

然后把 `await mockGetAnimals(...)` 改为 `await getAnimals(...)`，其余逻辑完全不变。

后端每实现一个模块，前端对照检查：

### 3.1 用户认证 ✅ 已有 Mock
- [ ] `POST /api/auth/login` 返回 `{ token, user }` → 存 `uni.setStorageSync('token', token)`
- [ ] `POST /api/auth/register` 返回格式与 mock 一致

### 3.2 鼻纹采集 ✅ 已有 Mock
- [ ] `POST /api/nose/collect` 返回 `{ vector_id, confidence_score, liveness_passed }`
- [ ] 注意：后端可能返回 `liveness_passed: false`，前端需展示"活体检测未通过，请重试"

### 3.3 鼻纹比对 ✅ 已有 Mock
- [ ] `POST /api/nose/compare` 返回 `fusion_score`、`vector_similarity`、`gps_distance_m`、`image_similarity`、`text_match_rate`

### 3.4 事件上报 ✅ 已有 Mock

## 四、常见问题处理

### 4.1 后端还没提供接口，本地怎么测试？

在 `mock.js` 里同时保留 mock 和真实 API 两套，用变量开关切换：

```javascript
// 切换开关：true = 用真实API，false = 用Mock
const USE_REAL_API = false

import { mockGetAnimals } from './mock.js'
import { getAnimals as realGetAnimals } from './api.js'

export function getAnimals(params) {
  if (USE_REAL_API) {
    return realGetAnimals(params)
  }
  return mockGetAnimals(params)
}
```

### 4.2 后端返回的图片 URL 是相对路径

后端返回的照片字段可能是相对路径如 `/uploads/photo.jpg`，前端需要拼接完整地址：

```javascript
// 在 api.js 的 request 封装中处理
const FULL_URL = BASE_URL.replace('/api', '')  // 去掉 /api

// 或者在页面中处理
const photoUrl = res.photo_url.startsWith('http')
  ? res.photo_url
  : 'http://localhost:3000' + res.photo_url
```

### 4.3 后端说跨域了怎么办

后端需要配置 CORS，允许小程序的域名。如果在真机上测试报跨域，确认：
- 后端设置了 `Access-Control-Allow-Origin: *`（开发环境）或具体域名
- 小程序开发者工具勾选了"不校验合法域名"（开发阶段）

### 4.4 token 过期了怎么办

后端返回 401 时，在 `request` 封装里自动跳转到登录页：

```javascript
if (res.statusCode === 401) {
  uni.removeStorageSync('token')
  uni.reLaunch({ url: '/pages/login/index' })
}
```

### 4.5 接口返回字段和 Mock 不一样

立即在群里反馈给后端，明确说明缺少哪个字段。参考 `docs/后端接口文档-给老师.md` 中的"联调检查清单"。

| 工作 | 负责人 | 依赖 |
|------|--------|------|
| 创建 `api.js` 基础封装 | 前端 | 无依赖 |
