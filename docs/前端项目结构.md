## 4. 页面路由映射

### 4.1 用户端（miniapp-user）

| 页面路径 | 页面名称 | 启动方式 |
|---------|---------|---------|
| `pages/index/index` | 首页 | TabBar 首页 |
| `pages/login/index` | 登录 | 首页自动跳转 |
| `pages/collect/index` | 鼻纹采集引导 | 首页悬浮按钮 |
| `pages/collect/result` | 比对结果 | 采集完成后跳转 |
| `pages/animal-detail/index` | 动物详情 | 首页列表点击 |
| `pages/claim/index` | 认领申请 | 动物详情页底部按钮 |
| `pages/user/index` | 个人中心 | TabBar 我的 |

### 4.2 管理端（miniapp-admin）

| 页面路径 | 页面名称 | 启动方式 |
|---------|---------|---------|
| `pages/admin/index` | 管理首页 | TabBar 首页 |
| `pages/admin/audit/index` | 审核中心 | 管理首页待办入口 |
| `pages/animals/index` | 动物档案管理 | TabBar 动物 |
| `pages/events/index` | 事件管理 | TabBar 事件 |
| `pages/users/index` | 用户管理 | TabBar 用户 |

## 5. 组件清单

### 5.1 用户端组件

| 组件路径 | 用途 | 传入参数 |
|---------|------|---------|
| `components/animal-card/index.vue` | 动物列表卡片 | `animal: Animal` |
| `components/nose-guide-box/index.vue` | 鼻纹采集引导框 | `species: string` |
| `components/fusion-score-panel/index.vue` | 四维度得分展示 | `result: CompareResult` |
| `components/match-result-card/index.vue` | 比对结果卡片 | `item: MatchItem` |

### 5.2 管理端组件

| 组件路径 | 用途 | 传入参数 |
|---------|------|---------|
| `components/audit-event-card/index.vue` | 事件审核卡片 | `event: Event` |
| `components/audit-claim-card/index.vue` | 认领审核卡片 | `claim: Claim` |
| `components/stat-card/index.vue` | 统计数字卡片 | `value: number, label: string` |

## 6. 静态资源规范

### 6.1 TabBar 图标尺寸
- 81 × 81 px（微信小程序要求）

### 6.2 Mock 占位图
- 使用 SVG 内联（可缩放，不占体积）
- 真实图片上线前用占位图替代

### 6.3 图标规范
- TabBar：`static/tab-*.png`（灰色未选中 / 主题色选中）
- 管理端主题色：`#FF6B6B`
- 用户端主题色：`#0FBF9F`
