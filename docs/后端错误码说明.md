# 后端错误码说明

## 错误码总览

| code | HTTP Status | message | 含义 | 前端处理方式 |
|------|------------|---------|------|-------------|
| 0 | 200 | success | 成功 | - |
| 40001 | 400 | 参数缺失 | 缺少必填字段 | 提示用户补全字段 |
| 40002 | 400 | 参数格式错误 | 字段类型/格式不对 | 提示正确格式 |
| 40003 | 400 | 参数校验失败 | 字段值不合法（如超出枚举范围） | 提示可选值 |
| 40101 | 401 | Token 过期 | JWT 已过期（7天） | 跳转登录页 |
| 40102 | 401 | Token 无效 | JWT 伪造/篡改/未提供 | 跳转登录页 |
| 40301 | 403 | 登录失败 | 手机号或密码错误 | 提示账号或密码错误 |
| 40302 | 403 | 禁止访问 | 非本人资源（如修改他人认领） | 提示无权限 |
| 40303 | 403 | 无权限 | role 不是 admin | 提示需要管理员权限 |
| 40401 | 404 | 资源不存在 | 动物/事件/认领/用户不存在 | 提示已删除或不存在 |
| 40402 | 404 | 页面不存在 | 路由未匹配 | 提示404 |
| 40901 | 409 | 资源冲突 | 重复提交（如重复认领同一动物） | 提示已申请 |
| 42201 | 422 | 条件不满足 | 认领需3个样本比对超85% | 提示鼻纹数据不足 |
| 50001 | 500 | 服务器错误 | 后端异常（数据库/代码错误） | 提示稍后重试 |
| 50002 | 500 | AI 服务超时 | AI 服务响应超过10秒 | 提示AI识别失败，稍后重试 |
| 50003 | 500 | AI 服务不可用 | AI 服务连接失败 | 降级返回 mock 数据 |

## Token 相关详细说明

### Token 过期

- **HTTP Status Code**：401
- **响应**：
  ```json
  {
    "code": 40101,
    "message": "Token 过期",
    "data": null
  }
  ```
- **前端处理**：清除 localStorage 中的 token，跳转登录页

### Token 无效（未提供/伪造/篡改）

- **HTTP Status Code**：401
- **响应**：
  ```json
  {
    "code": 40102,
    "message": "Token 无效",
    "data": null
  }
  ```
- **前端处理**：清除 localStorage 中的 token，跳转登录页

## AI 服务超时说明

当 `/nose/compare` 或 `/admin/events/:id/process` 调用 AI 服务超时时（>10s），前端收到：

- **HTTP Status Code**：200（业务层超时降级）
- **响应示例**：
  ```json
  {
    "code": 50002,
    "message": "AI 服务超时，已返回模拟数据",
    "data": {
      "similarity": 91.5,
      "match": true,
      "matched_animal_id": "42311cae-ae41-4ae0-b413-93672ca68f46",
      "message": "AI 服务超时，已返回模拟数据，实际相似度以真实AI返回为准"
    }
  }
  ```

说明：AI 超时后后端会降级返回 mock 数据，业务不中断。前端应判断 `code >= 50000` 时提示"AI识别失败"。

## 常见错误场景

### 1. 缺少必填字段
```json
// POST /events 时 body 为空
{
  "code": 40001,
  "message": "参数缺失",
  "data": null
}
```

### 2. 字段格式错误
```json
// POST /auth/login 时 password 传入数字
{
  "code": 40002,
  "message": "参数格式错误",
  "data": null
}
```

### 3. 非 admin 访问管理端
```json
// 普通用户访问 GET /admin/stats
{
  "code": 40303,
  "message": "无权限",
  "data": null
}
```

### 4. 资源不存在
```json
// GET /animals/not-exist-id
{
  "code": 40401,
  "message": "资源不存在",
  "data": null
}
```

### 5. 重复认领
```json
// POST /claims 但该动物已被其他用户认领
{
  "code": 40901,
  "message": "资源冲突",
  "data": null
}
```

### 6. 鼻纹样本不足
```json
// POST /claims 但该动物鼻纹样本少于3个
{
  "code": 42201,
  "message": "条件不满足",
  "data": null
}
```

### 7. 服务器错误
```json
// 数据库连接失败等
{
  "code": 50001,
  "message": "服务器错误",
  "data": null
}
```

## 错误码段划分

| 区间 | 含义 |
|------|------|
| 0 | 成功 |
| 40001-40099 | 客户端参数错误 |
| 40101-40199 | Token 相关错误 |
| 40301-40399 | 权限/认证错误 |
| 40401-40499 | 资源不存在 |
| 40901-40999 | 资源冲突 |
| 42201-42299 | 业务条件不满足 |
| 50001-50099 | 服务器错误 |
| 50002 | AI 服务超时（特殊） |
| 50003 | AI 服务不可用（特殊） |
