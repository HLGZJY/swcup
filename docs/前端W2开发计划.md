### 5.1 页面间数据传递

**方式一：URL Query（推荐用于简单数据）**

**方式二：Storage（用于需要在多页面共享的数据）**
```javascript
uni.setStorageSync('vector_id', vector_id)
// 目标页 uni.getStorageSync('vector_id')
```

### 5.2 GPS 得分计算（正确实现）

```javascript
/**
 * 计算位置维度得分
 * @param {number} distanceM - 两点距离（米）
 * @returns {number} 得分 0~1
 */
function calcLocationScore(distanceM) {
  if (distanceM <= 500) return 1.0
  if (distanceM >= 1500) return 0
  return Math.max(0, 1 - (distanceM - 500) / 1000)
}
```

### 5.3 融合得分计算

```javascript
function calcFusionScore(r) {
  // r.vector_similarity: 0~1
  // r.gps_distance_m: 米
  // r.image_similarity: 0~1
  // r.text_match_rate: 0~1
  const S_location = calcLocationScore(r.gps_distance_m)
  return (
    0.40 * r.vector_similarity +
    0.20 * S_location +
    0.20 * r.image_similarity +
    0.20 * r.text_match_rate
  )
}
```

### 5.4 Mock 延迟规范

| 接口类型 | 延迟 |
|---------|------|
| 纯数据查询（列表/详情） | 300~500ms |
| 需要计算（比对） | 1000~2000ms |
| 有上传（事件上报/认领） | 800~1200ms |
