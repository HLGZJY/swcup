## 7. 技术备忘

### GPS 评分公式（已修正）

```javascript
function calcLocationScore(distanceM) {
  if (distanceM <= 500) return 1.0
  if (distanceM >= 1500) return 0
  return Math.max(0, 1 - (distanceM - 500) / 1000)
}
```

### 融合得分计算

```javascript
fusion = 0.40 * vector_similarity
        + 0.20 * calcLocationScore(gps_distance_m)
        + 0.20 * image_similarity
        + 0.20 * text_match_rate
```

### Mock 延迟规范

| 接口类型 | 延迟 |
|---------|------|
| 纯数据查询 | 300~500ms |
| 比对计算 | 1000~2000ms |
| 有上传 | 800~1200ms |
