---

## 一、任务背景

前端已使用 Mock 数据完成了用户端和管理端的全部页面开发。后端（老师）需要根据前端整理的接口文档来实现 Node.js + MySQL 后端。

**你（前端）是接口的调用方，最清楚每个接口需要什么字段、返回什么数据。文档由你来主导编写，后端只是按图施工。**

## 二、文档编写要求

### 2.1 必须包含的内容

| # | 内容 | 说明 |
|---|------|------|
| 1 | **接口清单总表** | 所有 API 的请求方法、路径、功能说明 |
| 2 | **请求参数说明** | 每个接口的参数名、类型、是否必填、说明 |
| 3 | **响应数据说明** | 每个接口的返回字段、类型、含义 |
| 4 | **统一响应格式** | 规定 code/message/data 结构 |
| 5 | **认证机制说明** | JWT Token 如何传递、过期如何处理 |
| 6 | **错误码说明** | code 非 0 时的处理方式 |
| 7 | **文件上传规范** | 照片如何传输（base64/multipart）、大小限制 |
| 8 | **Mock 数据示例** | 完整的请求/响应 JSON 示例（从你的 mock.js 中提取） |

### 2.2 格式要求

- 格式：**Markdown**（方便老师阅读和复制）
- 文件名：`docs/前端接口文档-给老师.md`
- 中文编写，术语统一（参考 `docs/前端开发指南.md` 中的术语）
- 代码块使用 JSON，标注清楚"请求"和"响应"

## 四、接口字段对齐要求

### 4.1 对齐你的 mock.js

后端返回的数据格式必须和你的 `mock.js` 完全对齐。具体对照：

**用户端 `miniapp-user/src/services/mock.js`**：逐个函数整理每个返回字段的含义。

**管理端 `miniapp-admin/src/services/mock.js`**：逐个函数整理每个返回字段的含义。

### 4.2 特别重要的字段（容易出问题的地方）

以下字段必须明确说明，后端稍有偏差前端就会出问题：

| 字段 | 问题风险 | 要求 |
|------|----------|------|
| `fusion_score` | 融合得分的计算在后端算还是前端算？ | **后端算**，前端只展示 |
| `vector_id` | 采集接口返回的向量ID是什么格式？UUID？自增？ | 明确格式，建议 UUID |
| `status`（事件） | pending/confirmed/duplicated/linked/resolved/rejected 六种状态 | 全部枚举值必须列出 |
| `status`（动物） | lost/found/claimed/archived 四种状态 | 全部枚举值必须列出 |
| `gps_distance_m` | 比对接口里 GPS 距离由谁计算？ | **后端算**，传原始 lat/lng 让后端算 |
| `photos` | 照片是 base64 字符串还是 URL？多张怎么存？ | 明确是 URL 数组 |
| `todayResolved` / `todayProcessing` | 管理首页"今日概况"需要这两个字段 | 明确由后端统计当天数据 |

### 4.3 列出你页面中实际用到的所有字段

对着你的 Vue 页面，把每个 API 响应对象里**实际使用了哪些字段**全部列出来，不要遗漏。

操作方法：
1. 打开一个页面，比如 `pages/index/index.vue`
2. 找到所有 `uni.request` 或 mock 函数调用
3. 把响应结果 `.data` 里用到的每个字段标注出来
4. 重复这个步骤到所有页面

## 五、补充说明（帮后端少踩坑）

在文档末尾加上以下说明，降低后端联调时的沟通成本：

```
## 后端联调注意事项

1. 小程序不能直连 AI 服务（FastAPI），必须通过后端代调。后端需要内网调用 AI 服务后返回结果。

2. 鼻纹比对是重计算接口，响应可能较慢（1-3秒），建议前端显示 loading 状态。

3. GPS 距离计算需要纬度（lat）和经度（lng）原始值，由后端使用 Haversine 公式计算两点间距离。

4. 管理端接口（/api/admin/*）需要校验用户 role=admin，普通用户不应能访问。

5. 所有时间字段统一使用 ISO 8601 格式（2026-05-13T10:00:00Z）。

6. 图片上传建议限制大小（如 5MB），超出时前端已有提示。

7. CORS 需要后端配置，允许小程序的域名。
```
