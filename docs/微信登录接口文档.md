# 微信登录接口文档

> 日期：2026-05-13
> 背景：项目需求是微信一键登录（openid 机制），后端当前只有手机号+密码登录，需补充微信登录接口
> 参考：微信官方文档 https://developers.weixin.qq.com/miniprogram/dev/api-backend/open-api/login/auth.code2Session.html

---

## 一、完整登录流程

```
┌─────────┐                    ┌─────────┐                    ┌─────────────┐
│ 小程序   │                    │ 后端API  │                    │ 微信服务器   │
└────┬────┘                    └────┬────┘                    └──────┬──────┘
     │  1. wx.login()               │                              │
     │──────────────────────────────▶│                              │
     │  返回 { code: "xxxx" }        │                              │
     │◀─────────────────────────────│                              │
     │                              │  2. code2session              │
     │                              │─────────────────────────────▶│
     │                              │◀─────────────────────────────│
     │                              │  返回 openid/session_key     │
     │                              │  + unionid（如有）           │
     │                              │                              │
     │                              │  3. 查/创 users 表           │
     │                              │  4. 生成 JWT token           │
     │  5. 返回 { token, user }      │                              │
     │◀─────────────────────────────│                              │
```

**关键点**：
- 小程序前端**不**能直接访问微信服务器，必须通过后端转发
- `code` 只能使用一次，用完即废
- `session_key` 用于解密用户敏感数据（本项目暂不涉及）

---

## 二、后端接口规范

### POST /auth/weixin — 微信授权登录

**功能**：接收微信 code，换 openid，然后查库/创建用户，返回 JWT token

**请求**

```
POST /auth/weixin
Content-Type: application/json
```

```json
{
  "code": "xxxxxxxxxxxxxxxxxxxx"
}
```

**请求字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | wx.login() 返回的登录凭证 |

**成功响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "user_id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "nickname": null,
      "phone": null,
      "avatar_url": null,
      "role": "user",
      "created_at": "2026-05-13T12:00:00.000Z"
    }
  }
}
```

**失败响应**

| code | message | 场景 |
|------|---------|------|
| 40001 | 参数缺失 | 未传 code |
| 40304 | 微信授权失败 | code 无效或已过期 |
| 50001 | 服务器错误 | 调用微信接口失败 |

## 三、后端逻辑步骤

### Step 1：校验 code（必填）

```typescript
// auth.service.ts
async weixinLogin(code: string) {
  if (!code) throw new BadRequestException('参数缺失')
```

### Step 2：调用微信 jscode2session 接口

```typescript
// GET https://api.weixin.qq.com/sns/jscode2session
// ?appid=APPID
// &secret=SECRET
// &js_code=CODE
// &grant_type=authorization_code

const wxResponse = await axios.get('https://api.weixin.qq.com/sns/jscode2session', {
  params: {
    appid: process.env.WX_APPID,        // 小程序 appid
    secret: process.env.WX_SECRET,      // 小程序 appsecret
    js_code: code,
    grant_type: 'authorization_code'
  }
})
```

**微信返回字段**

| 字段 | 说明 |
|------|------|
| openid | 用户在当前小程序的唯一标识 |
| session_key | 会话密钥（用于解密，本项目暂不用） |
| unionid | 用户在开放平台的唯一标识（需绑定开放平台才返回） |

**微信错误返回**（errcode != 0）

| errcode | 说明 |
|---------|------|
| 40029 | code 无效 |
| 40125 | appid 或 appsecret 无效 |
| -1 | 系统繁忙 |

### Step 3：查询或创建用户

```typescript
// 根据 openid 查库
let user = await this.userRepository.findOne({ where: { openid } })

if (!user) {
  // 首次登录，创建用户
  user = this.userRepository.create({
    openid,
    role: 'user',          // 默认普通用户
    nickname: null,
    phone: null,
    avatar_url: null
  })
  await this.userRepository.save(user)
}
```

### Step 4：签发 JWT

```typescript
const payload = { sub: user.user_id, role: user.role }
const token = this.jwtService.sign(payload)
return { token, user }
```

## 四、users 表结构变更

需在 users 表增加 `openid` 字段（唯一索引）：

```sql
ALTER TABLE users ADD COLUMN openid VARCHAR(64) UNIQUE COMMENT '微信openid' AFTER phone;
```

> 注意：如果 `openid` 已存在则走登录逻辑，如果不存在则创建新用户（首次微信登录）。

## 五、环境变量配置

后端 `.env` 需新增：

```env
WX_APPID=wx_your_appid_here
WX_SECRET=your_appsecret_here
```

> 敏感信息不得提交到代码仓库，仅本地 `.env` 持有。

## 六、前端调用方式（UniApp）

```javascript
// pages/login/login.vue
async onWxLogin() {
  // 1. 获取微信登录凭证
  const [err, res] = await uni.login({ provider: 'weixin' })
  if (err || !res.code) {
    uni.showToast({ title: '微信登录失败', icon: 'none' })
    return
  }

  // 2. 发送到后端换 token
  const result = await uni.request({
    url: 'http://127.0.0.1:3000/auth/weixin',
    method: 'POST',
    data: { code: res.code }
  })

  if (result.data.code === 0) {
    // 3. 存 token
    localStorage.setItem('token', result.data.data.token)
    // 4. 跳转首页
    uni.reLaunch({ url: '/pages/index/index' })
  } else {
    uni.showToast({ title: result.data.message || '登录失败', icon: 'none' })
  }
}
```

**注意**：
- `provider: 'weixin'` 只在**微信小程序环境**下有效
- 在其他平台（H5/App）需做条件编译或降级处理
- 开发阶段需在微信开发者工具中勾选"不校验合法域名"（项目设置 → 详情 → 本地调试）

## 七、注意事项

1. **code 一次性**：`wx.login()` 获得的 code 只能用一次，重复使用会报 40029
2. **时效性**：code 有效期 5 分钟，超时需重新获取
3. **appid/secret 安全**：后端 `.env` 不能提交到 Git，需要后端在部署环境配置
4. **unionid**：只有小程序绑定到微信开放平台账号才返回 unionid，本项目暂时只用 openid
5. **session_key**：用于解密用户敏感数据（如手机号加密），本项目暂不涉及，但不应暴露
6. **重复登录**：同一 openid 再次登录应返回已有用户信息，不创建重复记录

## 八、与现有手机号登录的关系

| 登录方式 | 接口 | 首次登录 |
|---------|------|---------|
| 手机号+密码 | POST /auth/login | 手机号不存在报失败 |
| 手机号+密码 | POST /auth/register | 创建用户 |
| 微信授权 | POST /auth/weixin | openid 不存在则自动创建用户 |

两种登录方式**并行共存**，同一用户可以用手机号或微信登录（通过 openid 或 phone 关联）。
