## 二、建表脚本（按依赖顺序）

> 注意：外键依赖顺序很重要，先建被引用的表。
> 顺序：`users` → `animals` → `nose_features` → `rescue_events` → `claims` → `locations`

### 2.1 users（用户表）

```sql
CREATE TABLE users (
  user_id    VARCHAR(36)  PRIMARY KEY COMMENT 'UUID',
  nickname   VARCHAR(50)  NOT NULL COMMENT '昵称',
  phone      VARCHAR(20)  UNIQUE COMMENT '手机号（登录用）',
  avatar_url VARCHAR(255) COMMENT '头像 URL',
  role       ENUM('user','admin','org') DEFAULT 'user' COMMENT '角色',
  created_at DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '注册时间',
  updated_at DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_phone (phone),
  INDEX idx_role  (role)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 2.2 animals（动物档案表）

```sql
CREATE TABLE animals (
  animal_id      VARCHAR(36)  PRIMARY KEY COMMENT 'UUID',
  status         ENUM('lost','found','claimed','archived') DEFAULT 'lost' COMMENT '状态',
  species        ENUM('cat','dog','other') NOT NULL COMMENT '物种',
  breed          VARCHAR(50) COMMENT '品种',
  color          VARCHAR(50) COMMENT '毛色',
  gender         ENUM('male','female','unknown') DEFAULT 'unknown' COMMENT '性别',
  age_estimate   ENUM('puppy','adult','senior') COMMENT '年龄段',
  health_status  ENUM('healthy','injured','ill','unknown') DEFAULT 'unknown' COMMENT '健康状态',
  sterilized     BOOLEAN DEFAULT FALSE COMMENT '是否绝育',
  first_seen_at  DATETIME NOT NULL COMMENT '首次发现时间',
  last_seen_at   DATETIME NOT NULL COMMENT '最后出现时间',
  location_lat   DECIMAL(10,8) NOT NULL COMMENT '纬度',
  location_lng   DECIMAL(11,8) NOT NULL COMMENT '经度',
  address        VARCHAR(255) COMMENT '地址描述',
  notes          TEXT COMMENT '备注',
  tags           JSON COMMENT '标签数组',
  primary_nose_id VARCHAR(36) COMMENT '主鼻纹特征 ID',
  photos         JSON COMMENT '照片 URL 数组',
  created_at     DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  updated_at     DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_status      (status),
  INDEX idx_species     (species),
  INDEX idx_location    (location_lat, location_lng),
  INDEX idx_primary_nose (primary_nose_id),
  FOREIGN KEY (primary_nose_id) REFERENCES nose_features(vector_id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='动物档案表';
```

> ⚠️ `primary_nose_id` 外键依赖 `nose_features`，但建表顺序要求先建 `nose_features`。实际操作中建议：
> - **方案 A（推荐）**：先删掉 `animals` 建表语句里的这行外键，建完 `nose_features` 后再单独加。
> - **方案 B**：先建不含外键的 `animals`，等 `nose_features` 建好后再 `ALTER TABLE animals ADD FOREIGN KEY ...`。

### 2.3 nose_features（鼻纹特征表）

```sql
CREATE TABLE nose_features (
  vector_id          VARCHAR(36)  PRIMARY KEY COMMENT 'UUID',
  animal_id          VARCHAR(36)  NOT NULL COMMENT '关联动物 ID',
  feature_vector     LONGBLOB   NOT NULL COMMENT '512维 Float 数组（2048字节）',
  vector_dimension   INT          DEFAULT 512 COMMENT '向量维度',
  nose_photo_url    VARCHAR(255) NOT NULL COMMENT '鼻纹照片路径/URL',
  landmark_data      JSON COMMENT '关键点标注数据',
  confidence_score   DECIMAL(5,4) COMMENT '质量置信度 0~1',
  is_primary         BOOLEAN DEFAULT FALSE COMMENT '是否主特征',
  collection_angle   ENUM('front','left','right','top') DEFAULT 'front' COMMENT '采集角度',
  model_version      VARCHAR(50) NOT NULL COMMENT '模型版本',
  liveness_check_passed BOOLEAN DEFAULT FALSE COMMENT '活体检测是否通过',
  created_at         DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '采集时间',
  INDEX idx_animal (animal_id),
  INDEX idx_primary (animal_id, is_primary),
  FOREIGN KEY (animal_id) REFERENCES animals(animal_id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='鼻纹特征表';
```

> 注意：`feature_vector` 存储为 `LONGBLOB`（2048字节 = 512维 × 4字节 float32）。如果 AI 服务传过来的是 JSON 数组字符串，也可以用 `JSON` 类型，但 `BLOB` 更节省空间。

### 2.4 rescue_events（救助事件表）

```sql
CREATE TABLE rescue_events (
  event_id        VARCHAR(36) PRIMARY KEY COMMENT 'UUID',
  animal_id       VARCHAR(36) COMMENT '关联动物（null 表示新档案）',
  event_type      ENUM('report','rescue','medical','adopt','transfer','release') NOT NULL COMMENT '事件类型',
  reporter_id     VARCHAR(36) NOT NULL COMMENT '上报人 ID',
  station_id      VARCHAR(36) COMMENT '救助站 ID',
  occurred_at     DATETIME NOT NULL COMMENT '发生时间',
  location_lat    DECIMAL(10,8) NOT NULL COMMENT '纬度',
  location_lng    DECIMAL(11,8) NOT NULL COMMENT '经度',
  address         VARCHAR(255) COMMENT '地址描述',
  photos          JSON COMMENT '现场照片 URL 数组',
  nose_photo_url  VARCHAR(255) COMMENT '本次鼻纹照片 URL',
  description     TEXT COMMENT '事件描述',
  action_taken    TEXT COMMENT '已采取行动',
  is_duplicate    BOOLEAN DEFAULT FALSE COMMENT '是否重复',
  duplicate_of    VARCHAR(36) COMMENT '重复关联的动物 ID',
  fusion_score    DECIMAL(5,4) COMMENT '融合得分 0~1',
  status          ENUM('pending','confirmed','duplicated','linked','resolved','rejected') DEFAULT 'pending' COMMENT '状态',
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  INDEX idx_animal    (animal_id),
  INDEX idx_reporter  (reporter_id),
  INDEX idx_status    (status),
  INDEX idx_occurred  (occurred_at),
  FOREIGN KEY (animal_id)  REFERENCES animals(animal_id) ON DELETE SET NULL,
  FOREIGN KEY (reporter_id) REFERENCES users(user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='救助事件表';
```

### 2.5 claims（认领记录表）

```sql
CREATE TABLE claims (
  claim_id     VARCHAR(36) PRIMARY KEY COMMENT 'UUID',
  animal_id    VARCHAR(36) NOT NULL COMMENT '关联动物 ID',
  claimer_id   VARCHAR(36) NOT NULL COMMENT '认领人 ID',
  event_id     VARCHAR(36) COMMENT '关联事件 ID',
  claimed_at   DATETIME NOT NULL COMMENT '认领时间',
  status       ENUM('pending','approved','rejected','cancelled') DEFAULT 'pending' COMMENT '状态',
  notes        TEXT COMMENT '备注/证明说明',
  proof_photos JSON COMMENT '证明材料照片 URL 数组',
  approved_by  VARCHAR(36) COMMENT '审批管理员 ID',
  approved_at  DATETIME COMMENT '审批时间',
  created_at   DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  INDEX idx_animal   (animal_id),
  INDEX idx_claimer  (claimer_id),
  INDEX idx_status   (status),
  FOREIGN KEY (animal_id)  REFERENCES animals(animal_id),
  FOREIGN KEY (claimer_id) REFERENCES users(user_id),
  FOREIGN KEY (event_id)   REFERENCES rescue_events(event_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='认领记录表';
```

### 2.6 locations（位置记录表）

```sql
CREATE TABLE locations (
  location_id VARCHAR(36) PRIMARY KEY COMMENT 'UUID',
  animal_id   VARCHAR(36) COMMENT '关联动物 ID',
  event_id    VARCHAR(36) COMMENT '关联事件 ID',
  lat         DECIMAL(10,8) NOT NULL COMMENT '纬度',
  lng         DECIMAL(11,8) NOT NULL COMMENT '经度',
  address     VARCHAR(255) COMMENT '地址描述',
  recorded_at DATETIME NOT NULL COMMENT '记录时间',
  INDEX idx_animal (animal_id),
  INDEX idx_event  (event_id),
  INDEX idx_geo    (lat, lng)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='位置记录表';
```

## 五、快速执行脚本（完整版）

将以下内容保存为 `init.sql`，在 MySQL 客户端一次性执行：

```bash
mysql -u root -p nose_rescue < init.sql
```

完整 `init.sql` 内容即本文件的 **第二节（建表）+ 第三节（测试数据）**，请删除注释中的外键修复语句（`ALTER TABLE animals ADD FOREIGN KEY...`）并移至建表后执行。
