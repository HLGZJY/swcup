## 二、统一响应格式

所有接口统一使用以下 JSON 结构返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | number | 状态码，`0` 表示成功，非 `0` 表示失败 |
| `message` | string | 状态描述文字 |
| `data` | object/array | 业务数据，失败时通常为 `null` |

**成功示例：**

```json
{
  "code": 0,
  "message": "获取成功",
  "data": { "total": 42, "list": [...] }
}
```

**失败示例：**

```json
{
  "code": 401,
  "message": "Token 已过期，请重新登录",
  "data": null
}
```

## 三、认证机制

### 3.1 JWT Token

- 用户登录成功后，后端返回 `token` 字段，前端存入 `uni.setStorageSync('token', token)`
- 后续所有请求在 Header 中携带：`Authorization: Bearer <token>`
- 管理端接口需额外校验用户 `role = 'admin'`，非管理员请求返回 `403`

**Header 示例：**

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 3.2 错误码对应处理

| code | 说明 | 前端处理 |
|------|------|----------|
| 0 | 成功 | 正常解析 data |
| 400 | 请求参数错误 | 提示用户检查输入 |
| 401 | Token 过期或无效 | 跳转登录页 |
| 403 | 无权限（普通用户访问管理端） | 提示无权限 |
| 404 | 资源不存在 | 提示不存在 |
| 500 | 服务器内部错误 | 提示服务异常 |

## 四、文件上传规范

### 4.1 图片格式

- 支持格式：`jpg`、`jpeg`、`png`
- 建议限制大小：单张不超过 **5MB**
- 超出限制时前端已有提示：`图片大小不能超过5MB`

### 4.2 传输方式

- 鼻纹照片（`nose_photo`）：**base64 字符串**，在请求体 JSON 中传输
- 事件现场照片（`photos`）：**base64 字符串数组** `["base64...", "base64..."]`
- 头像（`avatar`）：URL 字符串，由后端上传后返回公开 URL

### 4.3 图片字段汇总

| 接口 | 字段 | 类型 | 说明 |
|------|------|------|------|
| POST /api/nose/collect | `nose_photo` | string (base64) | 鼻纹照片，必填 |
| POST /api/events | `photos` | array[string] (base64) | 现场照片，最多 9 张 |
| POST /api/claims | `proof_photos` | array[string] (base64) | 证明材料照片 |
| PUT /api/admin/animals | `photos` | array[string] (base64) | 动物照片 |

### 5.5 POST /api/nose/collect — 鼻纹采集

> ⚠️ 重要：此接口需要后端调用 AI 服务（FastAPI）完成活体检测和特征提取。小程序不能直连 AI 服务，必须通过后端代调。

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `nose_photo` | string (base64) | 是 | 鼻纹照片 base64（不带 data:image 前缀） |
| `species` | string | 是 | 物种：`dog` / `cat` / `other` |
| `location_lat` | number | 是 | 采集时纬度 |
| `location_lng` | number | 是 | 采集时经度 |
| `description` | string | 否 | 补充描述 |

**请求示例：**

```json
{
  "nose_photo": "/9j/4AAQSkZJRgABAQAAAQABAAD...",
  "species": "dog",
  "location_lat": 39.9042,
  "location_lng": 116.4074,
  "description": "鼻纹正面照，光照良好"
}
```

**响应示例：**

```json
{
  "code": 0,
  "message": "采集成功",
  "data": {
    "vector_id": "v1a2b3c4-d5e6-7890-abcd-ef1234567890",
    "confidence_score": 0.92,
    "liveness_passed": true
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `vector_id` | string (UUID) | 特征向量 ID，**前端跳转结果页时作为 URL 参数传递** |
| `confidence_score` | number (0~1) | 质量置信度 |
| `liveness_passed` | boolean | 活体检测是否通过 |

> ⚠️ `vector_id` 格式要求为 **UUID v4**，不可使用自增 ID，否则跨系统调用时无法对齐。

### 5.6 POST /api/nose/compare — 鼻纹比对

> ⚠️ 重要：融合得分由**后端计算**，前端只做展示。GPS 距离也由后端计算（传原始 lat/lng，后端用 Haversine 公式计算）。

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `vector_id` | string | 是 | 采集接口返回的 vector_id |
| `species` | string | 是 | 物种：`dog` / `cat` / `other` |
| `location_lat` | number | 是 | 当前位置纬度 |
| `location_lng` | number | 是 | 当前位置经度 |
| `description` | string | 否 | 文本描述（用于 text_match_rate） |
| `photo_base64` | string | 否 | 本次照片 base64（用于 image_similarity） |

**请求示例：**

```json
{
  "vector_id": "v1a2b3c4-d5e6-7890-abcd-ef1234567890",
  "species": "dog",
  "location_lat": 39.9042,
  "location_lng": 116.4074,
  "description": "黄白相间",
  "photo_base64": "/9j/4AAQSkZJRgABAQAAAQABAAD..."
}
```

**响应示例：**

```json
{
  "code": 0,
  "message": "比对完成",
  "data": {
    "total": 3,
    "results": [
      {
        "animal_id": "a001",
        "fusion_score": 0.91,
        "vector_similarity": 0.95,
        "gps_distance_m": 320,
        "image_similarity": 0.88,
        "text_match_rate": 0.80,
        "animal": {
          "animal_id": "a001",
          "species": "dog",
          "breed": "中华田园犬",
          "color": "黄白相间",
          "gender": "male",
          "status": "lost",
          "first_seen_at": "2026-05-01T10:00:00Z",
          "address": "北京市朝阳区建外SOHO",
          "photos": ["/static/mock/dog1.jpg"]
        }
      },
      {
        "animal_id": "a002",
        "fusion_score": 0.71,
        "vector_similarity": 0.89,
        "gps_distance_m": 1250,
        "image_similarity": 0.79,
        "text_match_rate": 0.72,
        "animal": { ... }
      },
      {
        "animal_id": "a003",
        "fusion_score": 0.63,
        "vector_similarity": 0.82,
        "gps_distance_m": 2100,
        "image_similarity": 0.71,
        "text_match_rate": 0.68,
        "animal": { ... }
      }
    ],
    "threshold_confirmed": 0.88,
    "threshold_suspected": 0.75
  }
}
```

**融合得分计算公式（后端实现）：**

```
fusion_score = 0.40 × sim_vector + 0.20 × S_location + 0.20 × sim_image + 0.20 × sim_text
```

其中 `S_location = max(0, 1 - (gps_distance_m - 500) / 1000)`，500m 内满分，1500m 外为 0。

**判定规则：**

| fusion_score | 判定 | 前端展示 |
|--------------|------|----------|
| ≥ 0.88 | 确认重复 | "确认重复"徽章 + 可申请认领 |
| 0.75 ~ 0.88 | 疑似重复 | "疑似重复，请审核"提示 |
| < 0.75 | 无匹配 | "未匹配，可新建档案" |

> ⚠️ 此接口为重计算接口，响应可能较慢（1-3秒），建议前端显示 loading 状态。

## 八、后端联调注意事项

1. **小程序不能直连 AI 服务**：所有 FastAPI 调用（活体检测、特征提取）必须由后端 Node.js 代调，不允许小程序绕过后端直接请求 AI 服务端口。

2. **鼻纹比对耗时**：POST /api/nose/compare 是重计算接口，响应可能较慢（1-3秒），请后端合理设置请求超时（建议 10s），前端已做 loading 状态处理。

3. **GPS 距离计算在后端**：gps_distance_m 由后端使用 Haversine 公式根据传入的 lat/lng 计算，前端只传原始经纬度。

4. **融合得分在后端计算**：fusion_score = 0.40×sim_vector + 0.20×S_location + 0.20×sim_image + 0.20×sim_text，由后端计算后返回，前端直接展示。

5. **管理端权限校验**：所有 /api/admin/* 接口需校验 JWT 中 role=admin，普通用户请求返回 403。

6. **图片大小限制**：建议后端限制上传图片 5MB 以内，超出时返回 413 状态码，前端已有对应提示。

7. **CORS 配置**：后端需配置 CORS，允许微信小程序的域名（开发阶段可暂时允许所有来源）。

8. **时间格式**：所有时间字段统一使用 ISO 8601 格式（`2026-05-13T10:00:00Z`），前端 moment.js 已处理解析。

9. **vector_id 格式**：鼻纹特征 ID 统一使用 **UUID v4** 格式（如 `v1a2b3c4-d5e6-7890-abcd-ef1234567890`），不可使用自增整数。

10. **photos 字段**：照片统一存为 URL 字符串数组 `["https://...", "https://..."]`，返回给前端时不要返回 base64（体积过大）。
