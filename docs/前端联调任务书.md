### 2.2 实现认证拦截器

**必须实现**，否则所有需认证接口都会 401。

参考 `docs/后端认证流程说明.md`：

```javascript
// 请求拦截器
uni.addRequestInterceptors({
  request: (config) => {
    const token = localStorage.getItem('token')
    if (token) {
      config.header = config.header || {}
      config.header['Authorization'] = 'Bearer ' + token
    }
    return config
  },
  fail: (err) => { return Promise.reject(err) }
})

// 响应拦截器（关键！）
uni.addResponseInterceptor({
  response: (res) => {
    const data = res.data
    // 统一错误处理
    if (data.code === 40101 || data.code === 40102) {
      localStorage.removeItem('token')
      uni.showToast({ title: '登录已过期，请重新登录', icon: 'none' })
      setTimeout(() => { uni.reLaunch({ url: '/pages/login/login' }) }, 1500)
      return Promise.reject(data)
    }
    if (data.code === 40303) {
      uni.showToast({ title: '无管理员权限', icon: 'none' })
      return Promise.reject(data)
    }
    if (data.code === 50002 || data.code === 50003) {
      uni.showToast({ title: 'AI识别失败，请稍后重试', icon: 'none' })
      return Promise.reject(data)
    }
    if (data.code !== 0) {
      uni.showToast({ title: data.message || '请求失败', icon: 'none' })
      return Promise.reject(data)
    }
    return data
  },
  fail: (err) => {
    uni.showToast({ title: '网络异常，请检查网络', icon: 'none' })
    return Promise.reject(err)
  }
})
```

### 2.4 登录/注册页面对接

**登录**：`POST /auth/login`
- 请求：`{ phone, password }`（注意字段名是小写，不是驼峰）
- 成功：存 `localStorage.setItem('token', data.token)`，跳转首页
- 失败：显示后端返回的 `message`

**注册**：`POST /auth/register`
- 请求：`{ phone, password, nickname }`
- 成功：自动登录，跳转首页（参考管理端代码 `onRegisterSuccess`）
