## 各页面 emoji → 图标替换清单

### 1. `pages/index/index.vue`

| 行 | emoji | 替换为 | 颜色 |
|----|-------|--------|------|
| 6 | 📍 | `<image src="/static/icons/icon-mappin.png">` | #0FBF9F |
| 12 | 🔍 | `<image src="/static/icons/icon-search.png">` | #999999 |
| 49 | 🐾 | 保留（空状态装饰性太强，换成 PNG 反而体积大） | - |
| 76 | ♂️♀️ | 保留（性别符文字级别，不值得换） | - |
| 81 | 🎨 | 保留（颜色图标太专用，emoji 最合适） | - |
| 85 | 📍 | `<image src="/static/icons/icon-mappin.png">` | #666666 |
| 97 | 鼻纹比对 文字按钮 | 保留（文字按钮换图标收益低） | - |

**替换方式：**
- `location-icon` class: `📍` → `<image src="/static/icons/icon-mappin.png" class="location-icon-img" />`
- `search-icon` class: `🔍` → `<image src="/static/icons/icon-search.png" class="search-icon-img" />`
- `detail-icon` class (卡片内): `📍` → 同上

**样式调整（添加到 `<style scoped>`）：**
```scss
.location-icon-img {
  width: 28rpx;
  height: 28rpx;
  margin-right: 8rpx;
  vertical-align: middle;
}
.search-icon-img {
  width: 28rpx;
  height: 28rpx;
  margin-right: 12rpx;
  vertical-align: middle;
}
.detail-icon {
  margin-right: 4rpx;
}
```

## 不替换的 emoji（理由）

| emoji | 原因 |
|-------|------|
| 🐾 | 空状态装饰，换PNG收益低 |
| ♂️♀️ | 性别符是文字级别，iconfont才适合 |
| 🎨 | 颜色图标过于专用 |
| ✅❌ | 绝育状态文字描述更准确 |
| 🏷️ | 标签语义，emoji直观 |
| 📋（时间线/标题） | 标题用emoji可接受 |
| ⚠️ | 警告emoji通用性强 |
| ❓ | 帮助通用符号 |
| ✎ | 太小，换了不明显 |
| › | chevron-right 已替换 |

## 风险

1. **登录页 paw 图标缺失** — 需要用户额外下载
2. **部分 emoji 替换后文字对齐可能偏移** — 需微调 CSS
3. **image 组件的默认适配** — 需设置 `mode="aspectFit"` 或固定宽高避免变形
