## 项目简介

本项目旨在设计并实现一个 **AI 驱动的流浪动物防重复救助系统**，通过 AI 技术识别同一只动物是否已被记录/救助过，避免重复投入资源，提升救助效率。

## 核心问题

- 同一只流浪动物被多个救助者分别发现并上报，导致重复救助
- 缺乏统一身份识别机制
- 救助资源（食物、医疗、场地）浪费

## 系统目标

1. 为每只动物建立唯一身份档案
2. 通过照片/外观特征识别重复个体
3. 实时检测重复上报
4. 提供救助资源分配优化建议
