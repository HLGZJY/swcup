# 鼻纹识别

## 核心要点

1. **定义**：利用深度学习提取宠物鼻纹的独特纹理特征，为每只动物生成唯一身份向量
2. **技术方案**：MobileNetV2 迁移学习，两阶段训练流程，128维特征向量输出
3. **核心优势**：鼻纹如同人类指纹，具有唯一性和稳定性，可作为动物身份识别的生物特征
4. **与通用图像识别的区别**：鼻纹识别专注于鼻部区域纹理，排除毛发颜色、体型等干扰因素

## 技术原理

### 为什么选择鼻纹？

- **唯一性**：每只动物的鼻纹纹理都是独一无二的，如同人类指纹
- **稳定性**：鼻纹不随年龄增长而显著变化
- **易获取**：宠物鼻部通常可以直接拍照，无需特殊设备
- **可靠性**：不受毛发颜色、长度、体型变化影响

### MobileNetV2 迁移学习

```
原始 ImageNet 预训练权重
        │
        ▼
替换分类头为 128 维输出层
        │
        ▼
┌───────────────────────────────────┐
│  阶段一：冻结 backbone，训练输出层  │  ← 5-10 epochs，快速收敛
│  (仅更新输出层权重)                  │
└───────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│  阶段二：解冻 backbone，低学习率微调 │  ← lr=1e-4，提升泛化能力
│  (全量数据训练)                     │
└───────────────────────────────────┘
        │
        ▼
  128 维特征向量（余弦相似度比对）
```

### 关键参数

| 参数 | 值 | 说明 |
|------|----|------|
| 特征向量维度 | 128 维 | 平衡精度与存储效率 |
| 阶段一学习率 | 1e-3 | 快速收敛 |
| 阶段二学习率 | 1e-4 | 低学习率微调 backbone |
| 阶段一 epochs | 5-10 | 仅训练输出层 |
| 阶段二 epochs | 按需 | 全量微调 |
| Baseline 目标 | Accuracy ≥ 70% | 验证集 Top-1 Accuracy |
| 优化后目标 | Accuracy ≥ 85% | W4 质量门控 |

## 数据集要求

### 数据采集

- **目标规模**：≥ 500 组（含正负样本对）
- **采集来源**：宠物照片征集 + 网上开源数据集（Pets-Face-Recognition 等）
- **边采集边标注**：不做二次返工
- **关键点标注**：鼻框中心 + 鼻翼（.json 文件存储）

### 数据增强

- 随机翻转（水平翻转）
- 随机旋转（±15°）
- 亮度调整
- 小角度畸变

### 损失函数

- 阶段一：CrossEntropyLoss（分类）
- 阶段二：Triplet Loss 或 Focal Loss（度量学习）

## 评测指标

| 指标 | 说明 | 目标 |
|------|------|------|
| Top-1 Accuracy | 最相似结果正确的比例 | ≥ 70%（baseline）/ ≥ 85%（优化后） |
| Top-5 Accuracy | Top-5 中包含正确结果的比例 | 越高越好 |
| Recall | 召回率，正确匹配被找回的比例 | ≥ 80% |
| F1 Score | Precision 和 Recall 的调和平均 | ≥ 80% |

## 活体检测

在鼻纹采集流程中加入活体检测模块，防止照片/视频欺骗：

- RGB 图像分析，判断是否为真实活体
- 集成到推理服务中
- W4 阶段完成（与模型优化并行）

## 参考项目分析

### dog-nose-print（轻量参考，VGG16）

路径：`/mnt/f/ai防重复救助/dog-nose-print/`

- **架构**：FastAPI + VGG16 (ImageNet pretrained, include_top=False)
- **输入**：224×224 狗鼻纹图
- **输出**：7×7×512 = 25088 维特征向量 → flatten 后直接用余弦相似度比对
- **API 端点**：
  - `POST /reg` — 注册新狗：提取特征 → 查重（精确匹配）→ 写入 SQLite
  - `POST /scanning` — 寻狗：提取特征 → 与全量特征库做余弦相似度 → 返回 Top-1
- **数据库**：SQLite，特征以 BLOB (float32 bytes) 存储
- **问题**：特征维度过高（25088维），无降维，纯比对效率低，无度量学习

### pets-face-recognition（完整方案，PyTorch Lightning）

路径：`/mnt/f/ai防重复救助/pets-face-recognition/`

- **三阶段流水线**：
  1. Mask R-CNN → 身体检测 + 分割
  2. Keypoint R-CNN → 头部检测 + 地标点
  3. 特征提取器 (FE) → 128/512 维向量
- **度量学习损失**：ArcFace (`cos(theta+m)`) 和 AddMargin (`cos(theta)-m`)，实现大间隔分类
- **骨干网络**：ResNet50 (512维) 或 MobileNetV2（移动端，128维）
- **数据集**：Oxford IIIT Pets、Petfinder cats/dogs、Kashtanka.pet
- **数据增强**：RandomRotation(5°)、RandomCrop(220)、RandomAutocontrast、Resize(224)
- **评估指标**：ROC AUC、Accuracy、candR@10/100（候选召回率）
- **训练配置** (`fe_dogs_config.py`)：
  - backbone: ResNet50 → 512维输出
  - 两阶段 LR：backbone 1e-2/2，fc层 1e-1，SGD momentum=0.9
  - LR scheduler：MultiStepLR [35, 45] epoch，50 epochs，batch_size=64
- **性能参考**：
  - Dog Head SGD: ROC AUC=0.973, Accuracy=93.8%
  - Ensemble (Head+Body): candR@100=0.735
