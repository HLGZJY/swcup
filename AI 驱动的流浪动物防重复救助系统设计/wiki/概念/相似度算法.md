# 相似度算法

## 核心要点

1. **目标**：计算两张动物照片的相似程度，判断是否为同一只动物
2. **输入**：两张图片（待检测图片 vs 档案图片）
3. **输出**：0-1 之间的相似度得分
4. **核心挑战**：同品种动物外观相似、照片角度/光照差异大

## 算法分类

### 方法一：深度学习特征提取 + 余弦相似度

**原理**：

```
图片A → [预训练CNN/ViT模型] → 特征向量V_A
图片B → [预训练CNN/ViT模型] → 特征向量V_B
相似度 = cosine_similarity(V_A, V_B)
```

**常用模型**：

| 模型 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| ResNet | 通用特征提取能力强 | 对细粒度区分一般 | 通用图像 |
| CLIP | 语义理解强 | 对外观细节一般 | 跨模态 |
| DINO | 细粒度特征好 | 计算量较大 | 动物识别 |
| 专用动物模型 | 针对动物优化 | 需要训练数据 | 生产环境 |

### 方法二：度量学习（Metric Learning）

**原理**：专门训练一个网络，使得同一动物的图片在特征空间中距离近，不同动物距离远。

**算法**：

| 算法 | 说明 |
|------|------|
| Triplet Loss | 三元组（锚点、正例、负例）训练 |
| Contrastive Loss | 对比损失，拉近正例、拉远负例 |
| ArcFace/CosFace | 人脸识别领域迁移，对类内差异容忍度高 |

### 方法三：图像哈希 + 局部特征

**原理**：提取图像全局哈希 + 局部关键点描述子。

**算法**：

| 算法 | 说明 |
|------|------|
| pHash/DHash | 感知哈希，速度快，适合缩略图匹配 |
| SIFT/ORB | 局部特征点，适合几何变化（旋转、遮挡） |
| SuperPoint | 深度学习关键点检测 |

## 混合策略

实际系统中通常组合多种方法：

```
综合得分 = w1 × 深度学习相似度
        + w2 × 度量学习相似度
        + w3 × 哈希相似度
        + w4 × 外观描述匹配度
```

权重 w1-w4 通过实际数据调优。

## 性能考量

| 指标 | 要求 | 说明 |
|------|------|------|
| 响应时间 | < 2s | 用户等待体验 |
| 吞吐量 | > 100 QPS | 并发上报场景 |
| 存储 | 特征向量 512-2048 维 | 向量数据库选型 |
