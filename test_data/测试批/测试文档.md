# 鼻纹智救 端到端测试文档

> **用途**: 验证近期修复的 6 个 bug 在小程序 + 后端链路上的行为是否符合预期
> **测试数据**: 当前文件夹下的 `A*` (动物图) + `aa*` (鼻纹图)
> **说明**:
> - `A1` / `A2` 视为**同一只**动物（同名同特征，不同角度）
> - `A3` ~ `A10` 各自是独立的动物
> - `aa*` 是对应动物编号的鼻纹（如 `aa1` 对应 `A1/A2`）
> - 没有 `aa2` / `aa6` —— 这两只动物没有鼻纹样本

### 方式 A：API + curl（最快，2 分钟）

> **假设**：后端在 `http://localhost:3000` 跑着、AI 服务在 `http://localhost:8000` 跑着。

#### A.1 — 拿 token（用你已有的任一用户）

```bash
# 随便选一个已有用户登录，拿 access_token
curl -s -X POST http://localhost:3000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800000001","code":"0000"}'
```

> 没建过用户？先用现有任意手机号（DB 里 24 个 user 随便挑一个看 phone），或者先注册一个。代码登录默认验证码是 `0000`（看 `auth.service.ts`）。

从返回里抄出 `access_token`，下面命令用 `$TOKEN` 占位。

#### A.2 — 上传 `A1.jpg` 提取鼻纹向量

```bash
curl -s -X POST http://localhost:8000/nose/collect \
  -F "image=@F:/swcup2026/test_data/测试批/A1.jpg" \
  -F "reporter_id=u-test"
```

**预期返回**:
```json
{
  "vector_id": "nose-uuid-xxxx",
  "vector": [0.012, -0.034, ...]   // 128 维数组
}
```

🔑 **把 `vector_id` 抄下来！** 后面要填进 A1 的 `primary_nose_id`。

#### A.3 — 建动物 A1

```bash
curl -s -X POST http://localhost:3000/animals \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "species": "dog",
    "breed": "柴犬",
    "color": "黄色",
    "gender": "male",
    "age_estimate": "2岁",
    "health_status": "健康",
    "sterilized": true,
    "address": "北京市朝阳区望京 SOHO",
    "location_lat": 39.9968,
    "location_lng": 116.4784,
    "notes": "测试动物 A1，右耳有缺口",
    "tags": ["测试"],
    "photos": ["http://localhost:3000/static/a1-thumb.jpg"],
    "primary_nose_id": "<A.2 返回的 vector_id>"
  }'
```

**预期返回**:
```json
{
  "animal_id": "<uuid>",
  "status": "lost",
  ...
}
```

🔑 **把 `animal_id` 抄下来！** 这就是 A1 的 ID。

#### A.4 — 验证 A1 已存在

```bash
curl -s "http://localhost:3000/animals?keyword=柴犬" -H "Authorization: Bearer $TOKEN"
```

应返回包含 `breed: "柴犬"`、`status: "lost"` 的 1 条记录。

## 5. 失败时的快速排查表

| 现象 | 大概率 Bug | 看哪里 |
| --- | --- | --- |
| 详情页"鼻纹比对"没带 `animal_id` | Bug 1 复发 | `pages/animal-detail/index.vue` `onCollect()` |
| 第二次选位置无反应 | Bug 2 复发 | `pages/collect/index.vue` `locationLocked` ref |
| 结果页图片空白 | Bug 3 复发 | `pages/collect/result.vue` `nose_photo_url` 解析 |
| 表单预览显示默认值 / 后端字段空 | Bug 4 复发 | `result.vue` `formAge/formHealth/...` + `apiNoseCompare` |
